# 开具发票

一般情况下，现金充值到账后，Zilliz Cloud 会自动发起开票申请，您无需手动申请。如果您已与 Zilliz Cloud 签订合同，且合同中约定了账期，则继续按原有流程手动申请开票。通过云市场结算的费用，由对应云市场开具发票。

本文介绍不同开票方式的适用范围，以及查看、下载和调整发票的方法。

## 开票方式\{#invoicing-method}

| **适用情况** | **开票方式** | **是否需要手动申请** |
| --- | --- | --- |
| 未在合同中约定账期 | 每笔现金充值入账后自动发起开票 | 不需要 |
| 已与 Zilliz Cloud 签订合同，且合同中约定了账期 | 保留原有手动开票流程，现金充值不触发自动开票 | 需要，按原有流程申请 |
| 阿里云云市场、亚马逊云科技 Marketplace | 由对应云市场开票 | 请按云市场的要求申请 |

开票方式以合同是否约定账期为区分依据，与购买按量计费还是包年包月服务无关。已签订合同但未约定账期的，仍按现金充值到账后自动申请开票的流程处理。

<Admonition type="info" title="说明">

同一笔资金不会重复开票。充值款已开票后，无论用于按量消费，还是支付包年包月新购、续费或升配订单，都不再开票。赠送金、优惠券和试用额度不开票。

</Admonition>

## 开票前准备\{#before-you-start}

开票前，请完成组织的企业认证，并确保开票资料准确、完整。企业认证操作请参考[企业认证](./enterprise-verification)。

请重点检查以下信息：

| **信息** | **说明** |
| --- | --- |
| 发票抬头 | 应与企业认证资料一致。 |
| 统一社会信用代码 | 用于开票的企业税号。 |
| 发票接收邮箱 | 用于接收开票结果和电子发票。 |

如果企业名称等认证信息发生变化，请在开票前及时[联系我们](https://support.zilliz.com.cn/)更新资料。

## 按充值自动开票\{#auto-invoicing-for-cash-recharge}

<Admonition type="info" title="说明">

本节适用于未在合同中约定账期的用户。现金充值到账后，系统会自动申请开票，无需您手动申请。

</Admonition>

### 开票规则\{#invoicing-rules}

- 每笔现金充值入账后，系统会自动发起开票，无需您手动申请。

- 每笔充值单独开具一张发票，开票金额等于该笔现金充值金额（含税）。

- 仅实际现金充值参与自动开票。赠送金、优惠券、试用额度的调整不触发自动开票。

- 已开票的充值款用于支付账单或订单时，不再重复开票。因欠费而补缴的现金充值，也按充值开票规则处理。

例如，您充值 ¥50,000 后，系统会按 ¥50,000 发起开票。之后使用其中 ¥48,000 支付包年包月续费订单时，该订单不再单独开票。

### 开票流程\{#invoicing-procedures}

<Procedures>

1. 现金充值到账后，系统检查合同是否约定账期，以及开票资料是否完整。

1. 对于合同中未约定账期且开票资料完整的用户，系统自动发起开票申请，默认开具**增值税专用发票**，预计在 **7 个工作日内**完成开票。

1. 开票成功后，电子发票发送至发票接收邮箱。

1. 您可以在开票历史中查看记录并下载发票。

</Procedures>

资料不完整时，开票暂停，待补齐后自动继续。开票处理异常时，请查看开票状态；如需帮助，请联系 [finance@zilliz.com](mailto:finance@zilliz.com)。

### 开票设置\{#invoicing-settings}

您可以在开票设置中修改自动开票的发票类型（增值税普通发票或增值税专用发票）、开户银行、银行账号和发票接收邮箱。

<Procedures>

1. 登录 Zilliz Cloud 控制台，选择目标组织。

1. 进入**费用中心 > 发票 > 开票历史**。

1. 点击**开票设置**。

1. 修改设置后点击**保存**。

</Procedures>

## 按账单和订单开票\{#invoicing-for-bills}

<Admonition type="info" title="说明">

本节仅适用于已与 Zilliz Cloud 签订合同，且合同中约定了账期的用户。

</Admonition>

此类用户继续按原有流程手动申请开票，现金充值不触发自动开票。账单确认和付款账期的说明，请参考[了解账单](./view-invoice)。

### 可开票金额\{#invoice-amount}

账单的可开票金额由符合开票条件的未结余额和现金余额扣款金额组成，但不包含：

- 赠送金、优惠券和试用额度抵扣的金额。

- 已在充值时开票的资金。

- 已通过其他适用流程开票的金额。

例如，组织现金余额中有 ¥8,000 已开票资金，之后使用这笔现金余额支付账单时，该 ¥8,000 不再计入可开票金额。

具体可开票金额请以控制台展示为准。

### 手动申请开票\{#manual-invoicing}

如果您已与 Zilliz Cloud 签订合同，且合同中约定了账期，请按以下原有流程手动申请开票。可申请的账单或订单及金额以控制台展示为准；已开票的充值金额不再重复开票。

<Procedures>

1. 选择组织并点击左侧导航栏中的**费用中心**。

1. 为账单和订单开具发票的入口所有不同：

    - 为账单开票：打开**发票**页签。点击**可开票账单**。勾选一张或多张您希望开具发票的账单。在底部提示栏上，您可查看已选中的开票账单数量及开票总金额。确认无误后，请点击**开票**按钮。

        ![invoicing-bills-cn](https://zdoc-images.oss-cn-hangzhou.aliyuncs.com/invoicing-bills-cn.png "invoicing-bills-cn")

    - 为订单开票：打开**发票**页签。点击**可开票订单**。勾选一张或多张您希望开具发票的订单。在底部提示栏上，您可查看已选中的开票订单数量及开票总金额。确认无误后，请点击**开票**按钮。

        ![invoicing-orders-cn](https://zdoc-images.oss-cn-hangzhou.aliyuncs.com/invoicing-orders-cn.png "invoicing-orders-cn")

1. 选择发票抬头类型。如选择个人抬头，Zilliz Cloud 仅支持开具增值税普通发票。如需开具增值税专用发票，请选择企业抬头。

    ![invoicing-cn](https://zdoc-images.oss-cn-hangzhou.aliyuncs.com/invoicing-cn.png "invoicing-cn")

1. 选择发票类型并填写所需开票信息。

    - 如选择开具增值税普通发票，相关参数请见下表。**发票抬头**和**统一社会信用代码**自动录入企业认证中的信息，且不可修改。

        | **参数** | **描述** |
        | --- | --- |
        | **发票备注（可选）** | 发票备注不得超过 50 个字符。 |
        | **发票接收邮箱** | 用于接收开票结果和发票的邮箱地址。最多可输入 5 个邮箱地址。 |

    - 如选择开具增值税专用发票，相关参数请见下表。**发票抬头**、**统一社会信用代码**、**注册地址**和**注册电话**自动录入企业认证中的信息，且不可修改。

        | **参数** | **描述** |
        | --- | --- |
        | **开户银行（可选）** | 你开立待登记银行帐户的银行名称 |
        | **银行帐户（可选）** | 待登记的银行帐户号码 |
        | **发票备注（可选）** | 发票备注不得超过 50 个字符。 |
        | **发票接收邮箱** | 用于接收开票结果和发票的邮箱地址。最多可输入 5 个邮箱地址。 |

1. 开票信息填写完毕并确认无误后，点击**申请开票**。

1. 我们预计在 1～3 个工作日后以邮件形式通知您开票结果。如开票成功，您可在 **Zilliz Cloud 开票成功**通知邮件中下载发票。

</Procedures>

## 退款与发票调整\{#refund-and-invoicing-adjustment}

退款是否需要调整发票，取决于资金退回的位置及原资金的开票情况。

| 场景 | 发票处理方式 |
| --- | --- |
| 包年包月退订，退款退回组织现金余额 | 不红冲原发票，也不重新开票。余额后续使用时不重复开票。 |
| 已开票的现金余额退回银行账户 | 按退款金额对对应发票进行红冲。 |
| 包年包月退订，退款直接退回银行账户 | 按退款金额处理对应发票红冲。 |
| 发票抬头或票种需要变更 | 联系[finance@zilliz.com](mailto:finance@zilliz.com)确认后，对原发票红冲并重新开具。 |

如需退款或调整发票，请联系 [finance@zilliz.com](mailto:finance@zilliz.com)。部分专用发票红冲可能需要确认，财务会告知您需要配合的操作。

## 通过云市场开票\{#invoicing-via-marketplace}

### 阿里云云市场\{#aliyun-marketplace}

通过阿里云云市场结算的费用，请在阿里云云市场申请发票。具体操作请参考阿里云的[发票申请](https://help.aliyun.com/document_detail/150571.html)说明。

### 亚马逊云科技 Marketplace\{#aws-marketplace}

通过亚马逊云科技 Marketplace 结算的费用，请按亚马逊云科技的发票流程办理。具体操作请参考其[发票信息指南](https://www.amazonaws.cn/support/fapiao/?nc1=h_ls)。

## 常见问题\{#faqs}

- **充值后需要手动申请发票吗？**

    一般情况下，现金充值到账后，系统会自动申请开票，无需您手动申请。

    如果您已与 Zilliz Cloud 签订合同，且合同中约定了账期，则继续按原有流程手动申请开票，充值不触发自动开票。

- **为什么账单或订单的可开票金额为 0？**

    如果相关资金已在充值时开票，后续消费或订单支付不能再次开票。请前往开票历史查看对应充值的发票。

- **包年包月新购、续费或升配后，还需要开票吗？**

    如果合同中未约定账期，现金充值到账后系统会自动申请开票。已开票的充值款用于支付包年包月新购、续费或升配订单时，无需再次申请开票。

    如果您已与 Zilliz Cloud 签订合同，且合同中约定了账期，购买包年包月服务后仍按原有流程手动申请开票。

- **一笔充值可以分成多张发票吗？**

    充值自动开票按每笔现金充值单独开具一张发票，金额等于该笔充值金额。

- **优惠券抵扣的金额可以开票吗？**

    不可以。赠送金、代金券和试用额度不开票。

- **充值后没有收到发票怎么办？**

    请检查：

    1. 合同中是否约定了账期。如果已约定账期，请按原有流程手动申请开票。

    1. 充值是否已入账。

    1. 企业认证和开票资料是否完整。

    1. 发票接收邮箱是否正确。

    1. 开票历史中是否已有对应记录。

    如仍有疑问，请联系 [finance@zilliz.com](mailto:finance@zilliz.com)。

- **企业名称变更后，如何更新发票抬头？**

    开票前，请先联系我们更新企业认证资料。已经开具的发票如需调整，请联系 [finance@zilliz.com](mailto:finance@zilliz.com)。

- **发票接收邮箱填错了怎么办？**

    已发送的邮件无法撤回。您可以在开票历史中下载发票，并核对后续开票使用的接收邮箱。

- **开票信息有误怎么办？**

    请联系 [finance@zilliz.com](mailto:finance@zilliz.com)。财务确认需要重开后，将关联处理原发票和新发票，避免重复开票。

- **可以申请纸质发票吗？**

    Zilliz Cloud 提供电子发票，不支持纸质发票申请。您可以通过开票通知邮件或控制台开票历史下载。

- **退款后是否需要红冲？**

    退款退回组织现金余额时，不红冲，也不开新票。已开票资金退回银行账户时，按退款金额处理对应发票红冲。详情请参考[退款与发票调整](./manage-invoice#refund-and-invoicing-adjustment)。
