# get

This operation gets a configuration value.

## Synopsis

```bash
zilliz configure get <KEY>
```

## Options

- **KEY** (*string*) -

    **[REQUIRED]**

    Indicates the name of the target configuration item.

## Example

```bash
zilliz configure get output
```
