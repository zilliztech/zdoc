# get

此操作获取一个配置值。

## 概要\{#synopsis}

```bash
zilliz configure get <KEY>
```

## 选项\{#options}

- **KEY** (*string*) -

    **[REQUIRED]**

    表示目标配置项的名称。

## 示例\{#example}

```bash
zilliz configure get output
```
