# current

此操作显示当前上下文。

## 简介\{#synopsis}

```bash
zilliz context current
[--output <json | table | text>]
```

## 选项\{#options}

- **--output, -o** (*string*) -

    指示输出格式。可选值：`json`、`table`、`text`。

## 示例\{#example}

```bash
zilliz context current
```
