# login

This operation logs you into Zilliz Cloud.

## Synopsis

```bash
zilliz login
[--no-browser]
[--api-key]
```

## Options

- **--no-browser** (*boolean*) -

    Indicates whether to automatically open the browser.

- **--api-key** (*boolean*) -

    Indicates whether to log in with an API key instead of a browser.

## Example

```bash
zilliz login
```
