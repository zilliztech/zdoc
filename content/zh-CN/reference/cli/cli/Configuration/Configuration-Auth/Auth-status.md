# status

此操作显示当前身份验证状态。

<strong>注意：</strong> `zilliz auth status` 是出于向后兼容性而保留的已弃用别名。在新脚本中，请使用 `zilliz whoami`（别名 `zilliz info`）。

## 概要\{#synopsis}

```bash
zilliz auth status
```

## 示例\{#example}

```bash
zilliz auth status
```
