# whoami

此操作会显示当前已登录的身份、解析后的控制平面 Endpoint，以及可切换到的组织列表。别名：`zilliz info`。

## 简介\{#synopsis}

```bash
zilliz whoami
```

## 示例\{#example}

```bash
zilliz whoami
```
