# BulkFileType

BulkFileType 实例保存 Milvus BulkWriter 支持的批量数据文件类型之一，以及该类型的数字代码和文件名后缀。

## 常量\{#constants}

- **PARQUET**

    将文件类型设置为 Parquet（*.parquet*）。

- **JSON**

    将文件类型设置为 JSON（*.json*）。

- **CSV**

    将文件类型设置为 CSV（*.csv*）。
