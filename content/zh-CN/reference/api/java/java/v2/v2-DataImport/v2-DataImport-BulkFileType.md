# BulkFileType

这是一个提供以下常量的枚举。

## 常量\{#constants}

- **PARQUET**

    将文件类型设置为 [Parquet](https://parquet.apache.org/) (*.parquet*)。

- **JSON**

    将文件类型设置为 JSON (*.json*)。

- **CSV**

    将文件类型设置为 CSV (*.csv*)。
