# ConsistencyLevel

ConsistencyLevel 实例是一种枚举常量，用于设置 Collection 上搜索和查询操作的一致性级别。

## 常量\{#constants}

- **STRONG**

    将一致性级别设置为 **Strong**，代码值为 0。

- **SESSION**

    将一致性级别设置为 **Session**，代码值为 1。

- **BOUNDED**

    将一致性级别设置为 **Bounded**，代码值为 2。

- **EVENTUALLY**

    将一致性级别设置为 **Eventually**，代码值为 3。
