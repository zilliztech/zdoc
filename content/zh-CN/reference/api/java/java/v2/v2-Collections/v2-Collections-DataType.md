# DataType

这是一个提供以下常量的枚举。

## 常量\{#constants}

- None(0)

    将数据类型设置为 **NoneType**。

- Bool(1)

    将数据类型设置为 **Boolean**。

- Int8(2)

    将数据类型设置为 **Int8**。

- Int16(3)

    将数据类型设置为 **Int16**。

- Int32(4)

    将数据类型设置为 **Int32**。

- Int64(5)

    将数据类型设置为 **Int64**。

- Float(10)

    将数据类型设置为 **Float**。

- Double(11)

    将数据类型设置为 **Double**。

- VarChar(21)

    将数据类型设置为 **VarChar**。

- Array(22)

    将数据类型设置为 **Array**。

- JSON(23)

    将数据类型设置为 **JSON**。

- Geometry(24)

    将数据类型设置为 **Geometry**。

- Timestamptz(26)

    将数据类型设置为 **Timestamptz**。

- BinaryVector(100)

    将数据类型设置为 **Binary Vector**。

- FloatVector(101)

    将数据类型设置为 **Float Vector**。

- Float16Vector(102)

    将数据类型设置为 **Float16 Vector**。

- BFloat16Vector(103)

    将数据类型设置为 **BFloat16 Vector**。

- SparseFloatVector(104)

    将数据类型设置为 **Sparse Vector**。

- Inv8Vector(105)

    将数据类型设置为 **Int8 Vector**。

- Struct(201)

    将数据类型设置为 **Struct**，它应作为 **Array** 字段的元素类型。
