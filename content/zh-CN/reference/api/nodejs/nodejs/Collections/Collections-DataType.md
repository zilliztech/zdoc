# DataType

这是一个提供以下常量的枚举。

## 常量\{#constants}

- NONE = 0

    将数据类型设置为 **NoneType**。

- BOOL = 1

    将数据类型设置为 **Boolean**。

- INT8 = 2

    将数据类型设置为 **Int8**。

- INT16 = 3

    将数据类型设置为 **Int64**。

- INT32 = 4

    将数据类型设置为 **Int32**。

- INT64 = 5

    将数据类型设置为 **Int64**。

- FLOAT = 10

    将数据类型设置为 **Float**。

- DOUBLE = 11

    将数据类型设置为 **Double**。

- VARCHAR = 21

    将数据类型设置为 **Varchar**。

- ARRAY = 22

    将数据类型设置为 **Array**。

- JSON = 23

    将数据类型设置为 **JSON**。

- Geometry = 24

    将数据类型设置为 **Geometry**。

- BinaryVector = 100

    将数据类型设置为 **Binary Vector**。

- FloatVector = 101

    将数据类型设置为 **Float Vector**。

- Float16Vector = 102

    将数据类型设置为 **Float16 Vector**。

- BFloat16Vector = 103

    将数据类型设置为 **BFloat16 Vector**。

- SparseFloatVector = 104

    将数据类型设置为 **Sparse Vector**。

- Int8Vector = 105

    将数据类型设置为 **Int8Vector**。

- Struct = 201

    将数据类型设置为 **Struct**。请注意，这仅适用于 **Array** 字段中的元素。
