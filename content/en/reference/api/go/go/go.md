# Go SDK Reference

The official Go SDK for Milvus and Zilliz Cloud provides a native Go client for vector database operations.

## Versions

- **[Go SDK v1](./v1)** — Legacy version (repository archived). Use only for existing applications.
- **[Go SDK v2](./v2)** — Current version, maintained in the main Milvus repository.

## Repositories

- **v1 (archived):** [milvus-io/milvus-sdk-go](https://github.com/milvus-io/milvus-sdk-go)
- **v2 (current):** [milvus-io/milvus/client](https://github.com/milvus-io/milvus/tree/master/client)
