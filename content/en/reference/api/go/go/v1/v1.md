# Go SDK Reference (v1)

<Admonition type="caution" title="Archived">
  The [milvus-io/milvus-sdk-go](https://github.com/milvus-io/milvus-sdk-go) repository has been archived and is now read-only. Please migrate to [Go SDK v2](./v2) for new development.
</Admonition>

This is the reference documentation for the Go SDK (version 1).

## Installation

```bash
go get -u github.com/milvus-io/milvus-sdk-go/v2
```

## Quick Start

```go
import "github.com/milvus-io/milvus-sdk-go/v2/client"

client, err := client.NewClient(context.Background(), client.Config{
   Address: "localhost:19530",
})
if err != nil {
    // handle error
}
defer client.Close()

client.HasCollection(context.Background(), "YOUR_COLLECTION_NAME")
```
