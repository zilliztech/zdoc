# Cnalphanumonly

The `cnalphanumonly` filter removes tokens that contain any characters other than Chinese characters, English letters, or digits.

## Configuration\{#configuration}

The `cnalphanumonly` filter is built into Zilliz Cloud. To use it, simply specify its name in the `filter` section within `analyzer_params`.

The `cnalphanumonly` filter operates on the terms generated by the tokenizer, so it must be used in combination with a tokenizer. For a list of tokenizers available in Zilliz Cloud, refer to [Jieba](./jieba-tokenizer) and its sibling pages.

After defining `analyzer_params`, you can apply them to a `VARCHAR` field when defining a collection schema. This allows Zilliz Cloud to process the text in that field using the specified analyzer for efficient tokenization and filtering. For details, refer to [Example use](./analyzer-overview#example-use).

    fmt.Println(err.Error())
