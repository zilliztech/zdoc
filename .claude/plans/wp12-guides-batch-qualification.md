# Guides batch qualification and collection Implementation Plan

> For agentic workers: use subagent-driven-development task-by-task; main conversation owns design and review.

**Goal:** Authenticate the already-discovered complete Guides group under a trusted v2 Fetch profile and collect real bounded evidence for every required member, while preserving the existing pilot v1 path and returning held without a candidate when any member or capacity check fails.

**Architecture:** Extend the existing Git authentication, measured provider and B1/Python paths; keep discovery explanations separate from full qualification. Current and future writer activation, production workflow scheduling, content Draft creation, and limit increases are outside this slice.

**Tech Stack:** TypeScript, Node, existing Python preparation bridge, Vitest and current workflow test selectors.

## Global Constraints

Follow the already-approved design in docs/implementation/tasks/WP12-zdoc-upstream-updates.md sections 2, 3 and 4. V2 lock normalization is derived only from validated Guides configuration at trusted M; v1 remains pilot-only. Authenticate each run/archive/receipt/publication/output/freshness; an equal profile alone grants no publication eligibility. Retain existing bounded raw Git transaction budget (16 calls,64MiB stdout,60 seconds,32MiB/20000-item list,64KiB lock),32MiB request,128MiB result,75-minute prepare,20-minute writer,16MiB/64-member producer archive. Any capacity failure holds the entire required group; no selected-page truncation or partial success. No capability serialization, JSON trust switch, source/real-lock/generated edits, automatic PR or Check writes, paid Translation, publication, workflow or security-boundary bypass. Preserve unrelated work and retained evidence.

API code blocks are concrete contracts to implement, never placeholder stubs to commit. M/D/T in prose mean the exact BatchPins keys master/dev/source. This plan is adopted after main and independent design reviews; no production activation or budget increase is authorized.
