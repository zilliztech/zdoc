# Dispatcher 加固：build 预检门（只拦源侧）+ 失败退避 + 飞书告警

一个 PR（feat/translation-dispatcher-guards，从 origin/master 切），三个 commit（①失败退避 ②build 门 ③飞书告警）。

**派发粒度不变**：全程保持 #757 的逗号组选择器，无任何 locale 拆分路径。结构性保证：源侧命中天然整组两轨同拦；目标侧命中一律不拦；退避的 markDispatched/失败计数按组对称，单轨只会以 cleared 离场，不会出现"blocked 且有 pending"的单轨残留。

## 门 1：build 预检（仅拦英文源侧）

- 仅在 armed 且本周期有选中时执行；dry 周期不变（~2 分钟）。
- dispatcher job 内建 dev 树 worktree（workflow 已 fetch `refs/remotes/origin/dev`；用 dev 自己的工具链 install 后跑 `build:en`——覆盖 en 内容健康度=两轨共同源，含 ja 目标文件诊断信号；不跑 build:zh-CN）。
- **归因**（translation-pending-count 扩展 `--print-files`，输出候选 sourcePath/targetPath，同源选择机制保证集合与实际派发一致）：
  - **命中 sourcePath（英文源坏）→ 该组整组不派（中日两轨一起停）**，本周期让位给其他组；dev 修复后 verdict 随 devSha 翻新自动恢复。
  - **仅命中 targetPath（某语种自有文件坏、源健康）→ 不拦照派**：坏文件在 pending 集内则本次重译即修复（派发是翻译文件的唯一修复回路，翻译产物不可手改）；不在 pending 集则告警提示需 full 模式重译或源变更。
  - **归因不出的红 → 整周期 safe-skip**（不派、不烧预算、无持久状态；fail-closed 防 parser 漏识别误放行）。
  - **绿 → 照常派发**。
- **无持久拦截状态**：每周期重估；verdict 按 devSha 缓存在 plan，dev 头不动不重跑 build。

## 门 2：失败退避（封堵每小时付费重试循环）

- 周期开始对 lastDispatch 非空 unit 查 runId conclusion（`gh run view`，查询失败→safe stop）；failure/cancelled/timed_out 计一次。
- 同一 `sourceCheckpointSha` 累计 **2 次**（常量可调）→ unit 转 `blocked`（非 open，不参与选择，summary 醒目）；checkpoint 移动经既有 supersede 路径自动重置预算，无需人工解锁。
- blocked 附带预填参数的 recovery 命令（`recover-translation.yml` + `previous_run_id` + `publish=false`）——失败 run 的正确善后是打捞已完成批次而非整组重派。

## 门 3：飞书告警（低频高信号，独立于全局静音）

- **事件集**：①源侧 build 拦截（组+坏文件清单+修复提示）；②未归因红 skip；③目标侧坏文件且不在 pending 集（需 full 重译或源变更的提示）；④退避 blocked（含预填 recovery 命令）。
- **按状态迁移去重**：首个事件 per（devSha+组）/ per（devSha）/ per（unit 检查点代），迁移判定复用 plan 的 verdict 缓存与 blocked 转移——不会每小时重复轰炸（那正是全局静音要消灭的噪音形态）。
- **发送**：dispatcher 把本周期告警写入 alerts.json（step 间交接）；新 workflow 步骤 `continue-on-error: true`，文件非空才发，复用现有 `pnpm docs-tooling report-card`（子命令按 CLI 实际面定，step 0 核实），env 照抄 fetch：`APP_ID`/`APP_SECRET`（secrets）+ `FEISHU_HOST`（var）。
- **kill switch 穿透**：全局 `FEISHU_NOTIFICATIONS_DISABLED` 现为 repo 级静音；告警步骤用 step 级 env 把该变量重指向独立 var `TRANSLATION_DISPATCHER_ALERTS_DISABLED`（默认未设=发送），全局静音继续管 fetch/translation 日常卡片，dispatcher 告警独立开关。零工具链改动。
- 发送失败只 warning，绝不失败 dispatcher 周期。

## 已知限制

- 文件级归因、组级拦截：一个坏英文源让整组两轨让路直到修复。
- 归因依赖 build 日志路径可解析；解析不到按未归因 skip 整周期。
- 目标侧坏文件且不在 pending 集时，门只告警不修复（自动流程本无解）。
