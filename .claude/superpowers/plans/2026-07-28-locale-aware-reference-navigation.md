# Locale-Aware Reference Navigation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore correct English, Japanese, and Chinese two-level navigation, publish isolated Chinese SDK Reference sidebars, and reject incomplete Chinese SDK landing pages before image creation.

**Architecture:** Keep one sidebar renderer, but move route classification and product-specific navigation decisions into pure shared modules. Select the generated Guides rail by site through the existing docs-ui Docusaurus plugin, load one explicit generated sidebar per Chinese SDK, and extend the existing `validate-reference --site zh-CN` gate with sidebar and landing-page contracts.

**Tech Stack:** TypeScript, React, Docusaurus 3, Vitest, pnpm, Node.js test runner, Playwright, Docker Buildx, Nginx

export type DocsLocale = 'en' | 'ja-JP' | 'zh-CN';
export type ReferenceTarget = 'python' | 'java' | 'go' | 'nodejs' | 'restful' | 'cli';

export type DocsRouteContext = Readonly<{
  locale: DocsLocale;
  localePrefix: '' | '/ja-JP';
  pathname: string;
  normalizedPathname: string;
  manual: 'guides' | 'reference' | 'byoc' | 'onpremise' | 'unknown';
  referenceTarget?: ReferenceTarget;
}>;

const TARGET_ALIASES: Readonly<Record<string, ReferenceTarget>> = Object.freeze({
  python: 'python', java: 'java', go: 'go', node: 'nodejs', nodejs: 'nodejs', restful: 'restful', cli: 'cli',
});

function normalize(pathname: string): string {
  const withoutQuery = pathname.split(/[?#]/u, 1)[0] || '/';
  return withoutQuery.replace(/\/+$/u, '') || '/';
}

export function parseDocsRoute(pathname: string, locale: DocsLocale): DocsRouteContext {
  const localePrefix = locale === 'ja-JP' ? '/ja-JP' : '';
  const path = normalize(pathname);
  const normalizedPathname = localePrefix && (path === localePrefix || path.startsWith(`${localePrefix}/`))
    ? normalize(path.slice(localePrefix.length) || '/')
    : path;
  const referenceMatch = normalizedPathname.match(/^\/reference\/([^/]+)/u);
  const manual = normalizedPathname === '/reference' || referenceMatch
    ? 'reference'
    : normalizedPathname.startsWith('/docs/byoc')
      ? 'byoc'
      : normalizedPathname.startsWith('/docs')
        ? 'guides'
        : normalizedPathname.startsWith('/on-premise')
          ? 'onpremise'
          : 'unknown';
  const referenceTarget = referenceMatch ? TARGET_ALIASES[referenceMatch[1]] : undefined;
  return {locale, localePrefix, pathname: path, normalizedPathname, manual, ...(referenceTarget ? {referenceTarget} : {})};
}

export function withLocalePrefix(href: string, context: DocsRouteContext): string {
  if (!href.startsWith('/') || href.startsWith('//') || context.localePrefix === '') return href;
  if (href === context.localePrefix || href.startsWith(`${context.localePrefix}/`)) return href;
  return `${context.localePrefix}${href}`;
}
```

import type {ReferenceTarget} from './docsRoute';

export type DocsSite = 'en' | 'zh-CN';
export type ReferenceNavigationTarget = Readonly<{
  kind: ReferenceTarget;
  label: string;
  landingHref: string;
  hrefPrefixes: readonly string[];
}>;
export type ManualReferenceNavigation = Readonly<{
  clientLibrariesLabel: string;
  toolsLabel: string;
  installSdksHref: string;
  toolsHref: string;
  targets: readonly ReferenceNavigationTarget[];
  entryRedirects: Readonly<Record<string, string>>;
}>;

const target = (kind: ReferenceTarget, label: string, landingHref: string, ...hrefPrefixes: string[]): ReferenceNavigationTarget =>
  Object.freeze({kind, label, landingHref, hrefPrefixes: Object.freeze([landingHref, ...hrefPrefixes])});

const EN = Object.freeze({
  clientLibrariesLabel: 'Client Libraries', toolsLabel: 'Tools',
  installSdksHref: '/docs/install-sdks', toolsHref: '/docs/agents-and-prompts',
  targets: Object.freeze([
    target('python', 'Python', '/reference/python'), target('java', 'Java', '/reference/java'),
    target('go', 'Go', '/reference/go'), target('nodejs', 'Node.js', '/reference/nodejs', '/reference/node'),
    target('restful', 'RESTful API', '/reference/restful'), target('cli', 'CLI', '/reference/cli'),
  ]),
  entryRedirects: Object.freeze({'/reference/cli/overview': '/reference/cli/cli/overview'}),
}) satisfies ManualReferenceNavigation;

const ZH_CN = Object.freeze({
  clientLibrariesLabel: '客户端参考', toolsLabel: '工具',
  installSdksHref: '/docs/install-sdks', toolsHref: '/docs/agents-and-prompts',
  targets: Object.freeze([
    target('python', 'Python SDK', '/reference/python'), target('java', 'Java SDK', '/reference/java'),
    target('go', 'Go SDK', '/reference/go'), target('nodejs', 'Node.js SDK', '/reference/nodejs', '/reference/node'),
    target('restful', 'RESTful API', '/reference/restful'), target('cli', 'Zilliz CLI', '/reference/cli'),
  ]),
  entryRedirects: Object.freeze({'/reference/cli/overview': '/reference/cli/cli/overview'}),
}) satisfies ManualReferenceNavigation;

export function getManualReferenceNavigation(site: DocsSite): ManualReferenceNavigation {
  return site === 'zh-CN' ? ZH_CN : EN;
}
```

- [ ] **Step 4: Implement the validator**

Export one entry point:

```ts
export function validateReferenceNavigation(options: Readonly<{
  repositoryRoot: string;
  site: 'en' | 'zh-CN';
}>): void;
```

Implementation requirements:

1. Parse `config/reference-navigation.json` with a strict Zod schema.
2. Load each site-owned CommonJS sidebar as a regular non-symlink file.
3. Recursively collect `doc` IDs and category structure.
4. Reject empty sidebars and IDs outside the target's `documentIdPrefix`.
5. Resolve every ID to exactly one `.md` or `.mdx` file under `content/<site>/reference`.
6. Require each configured landing page's document ID to appear in its sidebar.
7. Compare English and Chinese structural signatures while ignoring labels and allowing explicit paths from `config/reference-retirements.json`.
8. Strip front matter, imports, JSX-only lines, fenced-code contents, and Markdown punctuation before counting meaningful prose.
9. Count Markdown headings outside fenced code.
