For a StructArray field, existing entities return `NULL` for the new StructArray field across all its sub-fields. New entities must provide either `NULL` for the whole field or a valid value for every sub-field in every Struct element, except element-nullable sub-fields on Dedicated Clusters compatible with Milvus v3.0.x (not yet available on On-Demand Clusters). For a sub-field added to an existing StructArray field, existing entities return `NULL` for that sub-field in each Struct element.
