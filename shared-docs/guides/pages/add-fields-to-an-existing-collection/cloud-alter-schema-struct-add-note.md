After the StructArray field is added, entities that already exist in the collection return `NULL` for `chunks` across all its sub-fields. When you insert a new entity, every Struct element must provide a value for every sub-field, and a Struct element itself cannot be `NULL`. On Dedicated Clusters compatible with Milvus v3.0.x, element-nullable sub-fields may hold `NULL` in individual Struct elements; for details, refer to [Create a StructArray Field](create-structarray-field.md).
