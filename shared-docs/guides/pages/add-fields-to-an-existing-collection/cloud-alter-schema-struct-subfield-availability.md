- Adding a sub-field to an existing StructArray field is supported on Dedicated Clusters compatible with Milvus v3.0.x; it is not yet available on On-Demand Clusters. The added sub-field must allow element-level null (`nullable=True` on a scalar or vector sub-field, `element_nullable=True` on an array sub-field), cannot have a default value, and cannot be bound to an index in the same request.
