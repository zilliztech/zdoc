The nullable attribute is supported for both **scalar and vector fields** in a collection schema. On Free/Serverless and Dedicated Clusters, it is also supported on the parent StructArray field. Do not configure Struct subfields as nullable independently; define nullability on the StructArray parent and the setting is propagated to its subfields internally. Element-level null values are supported on Dedicated Clusters but not yet available on Free/Serverless Clusters.
