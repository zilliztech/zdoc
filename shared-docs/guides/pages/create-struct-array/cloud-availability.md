On Zilliz Cloud, nullable StructArray fields and dynamic StructArray field addition are supported on On-Demand Clusters. A StructArray field added dynamically must be nullable. Serving Clusters do not support these capabilities. Nullable vector arrays, element-level null values, scalar `ARRAY` subfields, and adding or dropping StructArray subfields are supported on Dedicated Clusters. These capabilities are not yet available on On-Demand and Serving Clusters.
