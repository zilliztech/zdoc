# md2md contract provenance

The blocks/ and preprocess/ directories are byte-for-byte copies of
`test/contract/cases/` at zilliztech/md2md commit
`a143b27c475059f1fe22e84e074953b05bd9cd37`, published as `@zilliz/mdtomd@1.3.0`.

These semantic cases run against the real adapter. Both the programmed fake
and the real adapter also run the shared WP0 shape contract.
