# describe

This operation gets details of a volume.

## Usage\{#usage}

```bash
zilliz volume describe [OPTIONS]
```

**OPTIONS:**

- **--name** (*string*) -

    **[REQUIRED]**

    Volume name.

## Example\{#example}

```bash
zilliz volume describe --name my-volume
```
