# whoami

This operation shows the currently signed-in identity, the resolved control-plane endpoint, and the list of organizations available to switch into. Alias: `zilliz info`.

## Synopsis\{#synopsis}

```bash
zilliz whoami
```

## Example\{#example}

```bash
zilliz whoami
```
