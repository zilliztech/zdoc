# clear

This operation removes the active cluster context. Cluster ID, endpoint, database, and plan are all cleared. Use this before switching organizations or when troubleshooting stale context state.

## Synopsis\{#synopsis}

```bash
zilliz context clear
```

## Example\{#example}

```bash
zilliz context clear
```
