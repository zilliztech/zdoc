# version

This operation shows the version of the installed Zilliz CLI.

## Synopsis\{#synopsis}

```bash
zilliz version
[--output <json | table | text>]
```

## Options\{#options}

- **--output, -o** (*string*) -

    Indicates the output format. Choices: `json`, `table`, `text`.

## Example\{#example}

```bash
zilliz version
```
