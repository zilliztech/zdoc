# ストレージリクエストコスト

ストレージリクエストコストは、ワークロードで使用されるオブジェクトストレージ API リクエスト操作を対象としています。

## ストレージリクエストコストの発生源\{#sources-of-storage-request-cost}

ワークロードが課金対象のオブジェクトストレージ API 操作を実行すると、ストレージリクエストコストが発生します。

リクエストは 2 つのクラスに分類されます：

- **クラス 1**: `PUT`, `COPY`, `POST`, `LIST`

- **クラス 2**: `GET`, `SELECT`

以下の操作では、Zilliz Cloud においてストレージリクエストコストが発生します：

- オンデマンドコンピューティングデータベース内のマネージドコレクションでインデックスの構築を行う場合。これにより、クラス 1 およびクラス 2 の両方のリクエストコストが発生します。

- インデックスのみがロードされている状態で、オンデマンドコンピューティングデータベース内のマネージドコレクションに対して検索を実行する場合。これにより、クラス 2 のリクエストコストが発生します。

- オブジェクトストレージからコールドデータを読み取る際、ティアードストレージサービングクラスター上で検索を実行する場合。これにより、クラス 2 のリクエストコストが発生します。

以下の操作では、ストレージリクエストコストは発生しません：

- 外部コレクションに対するすべての操作。

- オブジェクトストレージからオンデマンドコンピューティングデータベースへのデータインポート。

- パフォーマンス最適化または容量最適化サービングクラスター上でのインデックスの構築／検索。

### コスト計算\{#cost-calculation}

```plaintext
Storage Requests Cost = (Class 1 Request Count x Class 1 Unit Price)
                      + (Class 2 Request Count x Class 2 Unit Price)
```

- **クラス 1 リクエスト数**: クラス 1 リクエストの数。

- **クラス 2 リクエスト数**: クラス 2 リクエストの数。

- **単価**: クラウドリージョンとリクエストクラスによって決定されます。詳細については、[Zilliz Cloud の料金](https://zilliz.com/pricing/pricing-guide) をご覧ください。

## 例\{#example}

ある請求期間における使用量が以下の通りであると仮定します。

- **リージョン**: AWS us-east-1

- **クラス 1 リクエスト数**: 200,000

- **クラス 2 リクエスト数**: 1,200,000

単価は以下の通りです。

- **クラス 1 単価** = 100 万リクエストあたり &#36;5.00

- **クラス 2 単価** = 100 万リクエストあたり &#36;0.4

この場合、ストレージリクエストの総コストは `(0.2 x 5.00) + (1.2 x 0.40) = $1.48` となります。
