# ストレージコスト

Zilliz Cloud では、クラスターが実行中かどうかに関わらず、データまたはバックアップファイルを保存するとストレージコストが発生します。

## ストレージコストの発生源\{#sources-of-storage-costs}

以下のシナリオでストレージの課金が発生します。

- [リアルタイムサーブ](./cluster): サーブクラスターに保存されているデータ。

    - マネージドコレクション内のデータおよびインデックス。

    - 外部コレクション内のインデックス。

    - サーブクラスターのタイプが tiered-storage の場合、追加のコールドデータアクセスコストが発生する可能性があります。

- [オンデマンドコンピュート](./on-demand-compute): オンデマンドコンピュートデータベースに保存されているデータ。

    - マネージドコレクション内のデータおよびインデックス。

    - 外部コレクション内のインデックス。

- [バックアップ](./backup-and-restore) ストレージ: ディザスタリカバリ用に作成したバックアップファイル。

- [マネージドボリューム](./managed-volume) ストレージ: ボリュームに保存された構造化データまたは非構造化データファイルのコレクション。

## コスト計算\{#cost-calculation}

```plaintext
Storage Cost = Storage Unit Price x Data Size x Duration
```

- ストレージ単価: クラウドリージョンとクラスタータイプによって決定されます。詳細な料金については、[Zilliz Cloud 料金](https://zilliz.com/pricing) を参照してください。

- データサイズ: Zilliz Cloud に保存されているすべてのデータのサイズ、またはバックアップファイルのサイズで、GB単位で測定されます。

- 期間: データまたはバックアップファイルが Zilliz Cloud に保存されている時間の長さ。

### Cold data access\{#cold-data-access}

<Admonition type="info" icon="📘" title="Note">

<p>この請求項目は、Milvus 2.6.x と互換性のある階層型ストレージクラスターにのみ適用されます。 </p>

</Admonition>

クラスタータイプが **tiered-storage** の場合、追加のコールドデータアクセスコストが発生する可能性があります。以下の式は、コールドデータアクセスコストの計算方法を示しています。

```bash
Cold Data Access Cost =  Cold Data Access Unit Price x Cold Data Size
```

- コールドデータアクセス単価: クラウドリージョンによって決定されます。詳細な料金については、[Zilliz Cloud 料金ガイド](https://zilliz.com/pricing/pricing-guide) を参照してください。

- コールドデータサイズ: 検索またはクエリの各読み取りリクエストでスキャンされるオブジェクトストレージに保存されたコールドデータのサイズ。データサイズは GB で測定されます。

## 請求ルール\{#billing-rules}

クラスター、ボリュームストレージの請求ルールは、バックアップストレージおよびコールドデータアクセスとは若干異なります。

- **クラスターデータ、ボリューム、およびオンデマンドコンピュートデータベースストレージ:** 時間単位で請求され、最低課金時間は 1 時間です。

- **バックアップストレージ:** 日単位で請求され、最低課金期間は 1 日です。

- **コールドデータアクセス**: 読み取りリクエスト（検索またはクエリ）ごとに請求され、最低課金量は 1 MB です。1 MB を超えるリクエストは、実際にスキャンされたデータサイズに基づいて請求されます。

## 例\{#examples}

ストレージ費用の計算方法を理解するための例をいくつか示します。

### 例 1: データストレージ費用\{#example-1-data-storage-cost}

サービングクラスターの構成が以下の通りであると仮定します:

- **クラウドプロバイダーとリージョン**: AWS us-east-1 (バージニア)

- **クラスタータイプ**: パフォーマンス最適化済み

- **データサイズ**: 500 GB

- **ストレージ期間**: 29 日 23 時間 30 分

クラウドプロバイダーとリージョン、およびクラスタータイプの情報から、[料金ページ](https://zilliz.com/pricing) でストレージ単価が **&#36;0.025/GB 月** であることが確認できます。

[請求ルール](./storage-cost#billing-rules) により、1 時間未満の端数は 1 時間に切り上げられます。ストレージ期間の 29 日 23 時間 30 分は 30 日、つまり 1 ヶ月に切り上げられます。

データストレージ費用の合計は `$0.025 x 500 × 1 = $12.50` となります。

### 例 2: バックアップストレージ費用\{#example-2-backup-storage-cost}

クラスターの構成が以下の通りであると仮定します:

- **クラウドプロバイダーとリージョン**: AWS us-east-1 (バージニア)

- **クラスタータイプ**: パフォーマンス最適化済み

- **バックアップファイルサイズ**: 20 GB

- **バックアップファイル保持期間**: 44 日 6 時間

クラウドプロバイダーとリージョン、およびクラスタータイプの情報から、[料金ページ](https://zilliz.com/pricing) でストレージ単価が **&#36;0.025/GB 月** であることが確認できます。

[請求ルール](./storage-cost#billing-rules) により、1 日未満の端数は 1 日に切り上げられます。そのため、保持期間の 44 日 6 時間は 45 日、つまり 1.5 ヶ月に切り上げられます。

例のクラスターのバックアップストレージ費用の合計は `$0.025 x 20 x 1.5 = $0.75` となります。

### 例 3: マネージドボリュームストレージ費用\{#example-3-managed-volume-storage-cost}

ボリュームに **10 GB** のデータをアップロードしてインポートし、**1 ヶ月** 保持する場合、単価が **&#36;0.04/GB 月** であれば、費用は `$0.04 × 10 × 1 = $0.40` となります。

### 例 4: クラスターのコールドデータアクセス費用\{#example-4-cluster-cold-data-access-cost}

クラスターの構成が以下の通りであると仮定します:

- **クラウドプロバイダーとリージョン**: AWS us-east-1 (バージニア)

- **クラスタータイプ**: Tiered-storage

- **コールドデータサイズ**: 200 GB

クラウドプロバイダーとリージョン、およびクラスタータイプの情報から、[料金ガイド](https://zilliz.com/pricing/pricing-guide) でコールドデータアクセス単価が **&#36;0.0005/GB** であることが確認できます。

コールドデータアクセス費用の合計は `$0.0005 x 200 = $0.1` となります。

## よくある質問\{#faqs}

1. **クラスターを停止してもストレージ料金は発生しますか?**

    はい。クラスターが停止中であっても、クラスターデータ、バックアップ、またはボリュームファイルが保持されている限り、ストレージ費用が適用されます。

1. **ストレージに最低課金額はありますか?**
 はい。ストレージには最低課金額があります。

    - クラスターおよびボリュームストレージ: 最低 1 時間の課金。

    - バックアップストレージ: 最低 1 日の課金。
