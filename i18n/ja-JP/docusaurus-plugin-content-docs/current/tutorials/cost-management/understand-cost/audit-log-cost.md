# 監査ログのコスト

[監査ログ](./audit-logs) を有効にすると、Zilliz Cloud はログサービスをデプロイします。これらのログの収集、処理、転送には追加のシステムリソースが消費されるため、それに応じた料金が発生します。

監査ログ機能を使用するための総コストは、以下のコンポーネントの合計です：

- [監査ログの CU コスト](./audit-log-cost#audit-logs-cu-cost)：監査ログの収集と処理によって消費されるコンピューターリソースのコスト

- [データ転送コスト](./audit-log-cost#data-transfer-cost)：ログをオブジェクトストレージに転送する際のコスト。

## 監査ログの CU コスト\{#audit-logs-cu-cost}

```plaintext
Audit Logs CU Cost = Audit Logs CU Unit Price x Total Number of Query CU x Audit Logs Runtime
```

- **監査ログ CU 単価**: クラスターのリージョンとプロジェクトプランによって決定されます。詳細な料金については、[Zilliz Cloud 料金ガイド](https://zilliz.com/pricing/pricing-guide) をご参照ください。

- **クエリ CU 数の合計**: レプリカを考慮した、クラスター内のクエリ CU の総数です。

    ```plaintext
    Total Number of Query CU = Query CU × Replica Count
    ```

    たとえば、2 つのクエリ CU と 2 つのレプリカを持つクラスターの場合、CU の合計は 4 つになります。

- **監査ログ実行時間**: 監査ログ機能が有効になっている合計時間。実行時間は `無効化時点 − 有効化時点` として計算されます。クラスターが**一時停止**状態にある場合、その時間は計算から除外されます。これは、一時停止中は監査ログ機能によってコンピューティングリソースが消費されないためです。実行時間の計算例については、[例](./audit-log-cost#example) を参照してください。

## データ転送コスト\{#data-transfer-cost}

監査ログはオブジェクトストレージバケットに転送できます。現在、Zilliz Cloud では、クラスターと同じクラウドリージョンで作成されたオブジェクトストレージバケットへのログ転送のみをサポートしています。

同一リージョン内のデータ転送は、現時点では追加料金は発生しません。

データ転送の価格詳細については、[データ転送](./data-transfer-cost) を参照してください。

## 例\{#example}

クラスター構成が以下の通りであると仮定します。

- **プロジェクトプラン:** Enterprise

- **クラスターデプロイオプション**: Dedicated

- **クラウドプロバイダーとリージョン:** AWS us-east-1 (Virginia)

- **CU サイズ:** 8 CU

- **レプリカ数:** 2

- **監査ログ実行時間:** 

    ![JKGIwkjiyhRr2ebq4eKcUsZOn8d](https://zdoc-images.s3.us-west-2.amazonaws.com/JKGIwkjiyhRr2ebq4eKcUsZOn8d.png)

    上記の図に示すように、

    - 監査ログは 2025 年 8 月 1 日 12:00 に有効化されました。

    - クラスターは 2025 年 8 月 1 日 24:00 に一時停止されました。

    - クラスターは 2025 年 8 月 2 日 12:00 に再開され、2025 年 8 月 3 日 12:00 に削除されるまで稼働しました。

    合計実行時間は `(24 − 12) + 24 = 36 時間` です。

プロジェクトプランおよびクラウドプロバイダーとリージョンの情報に基づき、[価格ガイドページ](https://zilliz.com/pricing/pricing-guide) で確認すると、監査ログの単価は **&#36;0.031/時間** です。

CU サイズとレプリカ数の情報によると、合計クエリ CU サイズは `8 CU x 2 レプリカ = 16 CU` です。

監査ログの合計 CU コストは `$0.031 x 16 x 36 = $17.856` です。

同一リージョン内での転送であるため、データ転送コストは **&#36;0** です。

監査ログの合計コストは `$17.856 + $0.00 = $17.856` です。

## よくある質問\{#faqs}

1. **クラスターが一時停止されている場合、監査ログの料金は発生しますか？**
いいえ。監査ログの CU 料金は、機能が有効であり、かつクラスターが実際に稼働している間のみ適用されます。「一時停止」状態の時間は除外されます。

1. **監査ログを転送する際、データ転送料は発生しますか？**
同一リージョン内での転送は無料です。クロスリージョン転送（現在はサポートされていません）の場合は、追加料金が発生する可能性があります。

1. **監査ログが有効になっていても、実際にログが生成されない場合でも課金されますか？**
はい。監査ログの CU 料金は、ログが生成されているかどうかに関わらず、機能が有効になっている間のクラスターのクエリ CU サイズと実行時間に基づいて課金されます。ログが生成されない場合、データ転送コストは &#36;0 になる可能性があります。

1. **実際に生成されるログの量（例：高い QPS ワークロード対低い QPS ワークロード）に応じて請求額は変動しますか？**
いいえ。監査ログの CU コストは、生成されるログの量ではなく、クラスターのクエリ CU サイズと実行時間のみに依存します。
