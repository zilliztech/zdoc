## よくある質問




### 各クラウドプロバイダーの Marketplace 経由でサブスクライブした場合、AWS、GCP、または Azure のクレジットを Zilliz Cloud の利用料金に充当できますか？\{#can-i-use-aws-gcp-or-azure-credits-to-offset-zilliz-cloud-usage-when-subscribed-via-their-respective-marketplaces}

いいえ。AWS、GCP、Azure などのクラウドプロバイダーのクレジットを、たとえそれぞれの Marketplace 経由でサブスクライブした場合でも、Zilliz Cloud の利用料金に充当することはできません。

Zilliz Cloud の利用料金は、各クラウドプロバイダーの Marketplace を通じてサードパーティサービスとして請求されます。また、クラウドプロバイダーが提供する多くのプロモーションクレジットやコミットメント利用クレジットは、そのクラウドプロバイダー独自のサービスにのみ適用され、サードパーティの Marketplace 購入には適用されません。

詳細については、これらのクラウドプロバイダーが提供する利用規約を参照してください。以下は、それらの規約からの抜粋です。

- [AWS Credits Terms](https://aws.amazon.com/awscredits/): AWS クレジットは AWS アカウントに適用され、AWS サービスに対してのみ有効です。

- [Google Cloud Marketplace Terms](https://cloud.google.com/marketplace?hl=en): GCP クレジットは通常、Google Cloud サービスにのみ適用されます。

- [Azure Credit Usage Guidance](https://learn.microsoft.com/en-us/azure/cost-management-billing/understand/understand-azure-marketplace-charges): Visual Studio などのクレジットは、通常サードパーティの Marketplace オファーには適用されません。

### クレジットカードを追加した後、アカウントに残っている期限切れのクレジットを引き続き使用できますか？\{#after-adding-a-credit-card-can-i-continue-to-use-the-expired-credits-left-in-my-account}

はい。アカウントにまだ利用可能なクレジットが残っており、支払い方法を追加している場合、残りのクレジットの有効期限は 1 年に延長されます。

### &#36;100 のクレジットは期限切れになりますか？無料クレジットの有効期限を延長するにはどうすればよいですか？\{#will-my-and36100-credits-expire-how-can-i-extend-the-expiration-of-the-free-credits}

初めてビジネス用メールアドレスでアカウントを登録すると、30 日以内に使用できる &#36;100 のクレジットを受け取ります。クレジットの有効期限が近づいたら、支払い方法を追加することで有効期限を延長できます。その後、1 年以内に使用できる追加の &#36;100 のクレジットを受け取ります。

### Recycle Bin 内のデータには料金がかかりますか？\{#is-data-in-the-recycle-bin-charged}

いいえ。Recycle Bin 内の削除済みデータに対して料金は発生しません。
