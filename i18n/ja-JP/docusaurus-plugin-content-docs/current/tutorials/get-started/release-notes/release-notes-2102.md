# リリースノート (2024年10月14日)

この Zilliz Cloud のリリースでは、いくつかの重要なアップデートが導入されています。**ノートブックギャラリー** は、RAG、エンベディング、マルチモーダル検索などの高度な機能に関する例を提供します。**パフォーマンス最適化済み CU の容量向上** では、50%増加し、1 CUあたり最大150万個の768次元ベクトルを収容でき、大量データの場合、コストを最大30%削減できる可能性があります。**マルチレプリカ可用性** は、ワークロードとレプリカをアベイラビリティゾーン（AZ）間で分散させることで、クエリパフォーマンスと信頼性を向上させます。さらに、Zilliz Cloud はアジア太平洋地域でのパフォーマンス向上のため **AWS Tokyo リージョン** をサポートし、リアルタイム監視とトラブルシューティングのための **Prometheus連携**、および SSO を含む複数のログイン方法を提供する **Auth0 を使用した認証およびログインシステムの刷新** を実現しました。最後に、ユーザーは **AWS Marketplace 無料トライアル** を通じて Zilliz 製品を評価でき、パフォーマンスとスケーラビリティのテストのためにコア機能へのリスクフリーなアクセスを提供します。

### Milvus 互換性\{#milvus-compatibility}

このリリースは **Milvus 2.4.x** と互換性があります。

### ノートブックギャラリー\{#notebook-gallery}

このリリースでは、Zilliz Cloud にノートブックギャラリーが導入されました。このギャラリーでは、Zilliz Cloud の高度な機能を紹介する詳細な例を提供しています。ノートブックは、RAG（Retrieval-Augmented Generation）、エージェント、エンベディング、テキスト検索、マルチモーダル検索、データ取り込み、移行、パフォーマンス最適化など、幅広いユースケースをカバーしています。

今すぐ [ノートブック](https://zilliz.com/learn/milvus-notebooks) を探索しましょう！

### パフォーマンス最適化済み CU の容量向上\{#improved-capacity-of-performance-optimized-cu}

このリリースでは、パフォーマンス最適化済み CU（Compute Unit）の容量が50%増加しました。以前は、パフォーマンス最適化済み CU 1つあたり、768次元ベクトルで換算すると約100万個のベクトルを保持できました。現在は、1 CUあたり150万個のベクトルという容量に向上しています。大量データの場合、この改善により CU コストを約30%削減できます。

### マルチレプリカの一般提供\{#multi-replica-generally-available}

マルチレプリカが Zilliz Cloud で一般提供されるようになり、クラスタレベルのレプリケーションによりクエリスループットと可用性の両方を向上させることができます。

- **クエリパフォーマンスの向上**: 高いクエリ/秒（QPS）が必要なユーザーにとって、マルチレプリカによりクエリワークロードをレプリカ間で分散させることができます。この並列処理により、全体的なスループットが向上し、レイテンシが削減され、クエリ集約型アプリケーションの効率が改善されます。ほとんどの場合、レプリカを追加するにつれて全体的な QPS は線形に改善されます。

- **可用性の向上**: マルチレプリカは、レプリカを複数のアベイラビリティゾーン（AZ）に分散させることで可用性を強化します。この構成により、AZ の停止が発生した場合でもデータへのアクセスが継続され、ミッションクリティカルなアプリケーションに対してより高い信頼性を提供します。

- マルチレプリカの構成の詳細については、[レプリカの管理](./manage-replica) を参照してください。

### 新しいリージョンの利用可能: AWS Tokyo\{#new-region-available-aws-tokyo}

Zilliz Cloud が AWS Tokyo リージョン（ap-northeast-1）で利用可能になり、アジア太平洋地域のユーザーに対してレイテンシとパフォーマンスの向上を提供します。

AWS Tokyo リージョンの料金詳細については、[料金ページ](https://zilliz.com/pricing) をご覧ください。

### Prometheus連携のサポート\{#prometheus-integration-support}

Zilliz Cloud は Prometheus との連携をサポートするようになり、ユーザーはシステムメトリクスをリアルタイムで監視および可視化できるようになりました。この連携により、ユーザーはパフォーマンス、リソース使用量、システム健全性を追跡でき、プロアクティブな監視と効率的なトラブルシューティングを実現します。セットアップと構成の詳細については、[Prometheus との連携](./prometheus-monitoring) を参照してください。

### Auth0 を使用した認証およびログインシステムのリファクタリング\{#authentication-and-login-system-refactoring-with-auth0}

このリリースでは、Zilliz Cloud は Auth0 を使用して認証およびログインシステムを刷新しました。Zilliz Cloud は現在、3つのログイン方法をサポートしています：

- Eメールによる登録およびログイン。

- GitHub または Google 認証によるクイックログイン。

- エンタープライズ顧客向けの SSO ログイン。詳細については、[Okta によるシングルサインオン](./single-sign-on) をご覧ください。

### AWS Marketplace 無料トライアル\{#aws-marketplace-free-trial}

このリリースでは、Zilliz Cloud ユーザーは AWS Marketplace 無料トライアルオプションを利用でき、大規模な購入決定を行う前に、リスクフリーな環境で Zilliz 製品を探索および評価する機会を提供します。このトライアルでは、プラットフォームのコア機能への完全なアクセスが許可され、ユーザーはパフォーマンス、スケーラビリティ、およびアプリケーションとの互換性を徹底的にテストできます。

[AWS Marketplace: Zilliz](https://aws.amazon.com/marketplace/seller-profile?id=4922a541-e428-480d-8e32-db4ee9a7f46e) から Zilliz サービスを入手してください。
