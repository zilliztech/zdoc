# リリースノート（2024年10月14日）

今回の Zilliz Cloud のリリースでは、いくつかの重要なアップデートが導入されています。**ノートブックギャラリー**では、RAG、埋め込み（embeddings）、マルチモーダル検索などの高度な機能に関する使用例を提供します。**パフォーマンス最適化済み CU の容量が 50% 向上**し、1 CU あたり最大 150 万件の 768 次元ベクトルを格納できるようになり、大規模データ量の場合、コストを最大 30% 削減できる可能性があります。また、**マルチレプリカ可用性**により、ワークロードとレプリカを複数のアベイラビリティゾーン（AZ）に分散させることで、クエリパフォーマンスと信頼性が向上します。さらに、アジア太平洋地域におけるパフォーマンス向上のために **AWS 東京リージョン**がサポートされ、リアルタイム監視およびトラブルシューティングを可能にする **Prometheus連携**、そして Auth0 を活用した複数のログイン方法（SSO を含む）を提供する刷新された**認証・ログインシステム**も導入されました。最後に、ユーザーは **AWS Marketplace 無料トライアル**を通じて、リスクなく Zilliz 製品のコア機能を評価し、パフォーマンスやスケーラビリティのテストを行うことができます。

### Milvus 互換性\{#milvus-compatibility}

このリリースは **Milvus 2.4.x** と互換性があります。

### ノートブックギャラリー\{#notebook-gallery}

今回のリリースでは、Zilliz Cloud にノートブックギャラリーが導入されました。このギャラリーには、Zilliz Cloud の高度な機能を活用した詳細な使用例が掲載されています。ノートブックでは、RAG（Retrieval-Augmented Generation）、エージェント、埋め込み（embeddings）、テキスト検索、マルチモーダル検索、データ取り込み、移行、パフォーマンス最適化など、幅広いユースケースをカバーしています。

今すぐ [ノートブック](https://zilliz.com/learn/milvus-notebooks) をご覧ください！

### パフォーマンス最適化済み CU の容量向上\{#improved-capacity-of-performance-optimized-cu}

今回のリリースにより、パフォーマンス最適化済み CU（Compute Unit）の容量が 50% 増加しました。以前は、768 次元ベクトルを基準とした場合、各パフォーマンス最適化済み CU は約 100 万件のベクトルを保持できましたが、現在は 1 CU あたり 150 万件まで格納可能になりました。大規模なデータ量を扱う場合、この改善により CU コストを約 30% 削減できます。

### マルチレプリカの一般提供\{#multi-replica-generally-available}

マルチレプリカ機能が Zilliz Cloud で一般提供されるようになりました。これにより、クラスタレベルでのレプリケーションが可能となり、クエリスループットと可用性の両方が向上します。

- **クエリパフォーマンスの向上**: 高い QPS（1 秒あたりのクエリ数）を必要とするユーザーにとって、マルチレプリカによりクエリワークロードを複数のレプリカに分散できます。この並列処理によって全体的なスループットが向上し、レイテンシが低下し、クエリ集中型アプリケーションの効率が高まります。多くの場合、レプリカを追加することで全体の QPS が線形に向上します。

- **可用性の向上**: マルチレプリカは、複数のアベイラビリティゾーン（AZ）にレプリカを分散配置することで可用性を強化します。この構成により、AZ 障害が発生してもデータへの継続的なアクセスが保証され、ミッションクリティカルなアプリケーションに対して高い信頼性を提供します。

- マルチレプリカの設定方法については、[レプリカの管理](./manage-replica) を参照してください。

### 新しいリージョン：AWS 東京\{#new-region-available-aws-tokyo}

Zilliz Cloud が AWS 東京リージョン（ap-northeast-1）で利用可能になり、アジア太平洋地域のユーザーはレイテンシとパフォーマンスの向上を享受できます。

AWS 東京リージョンの料金詳細については、[料金ページ](https://zilliz.com/pricing) をご確認ください。

### Prometheus 連携のサポート\{#prometheus-integration-support}

Zilliz Cloud は Prometheus との連携をサポートするようになりました。これにより、ユーザーはシステムメトリクスをリアルタイムで監視・可視化できます。この連携により、パフォーマンス、リソース使用状況、システムの健全性を追跡でき、プロアクティブな監視と効率的なトラブルシューティングが可能になります。セットアップおよび設定の詳細については、[Prometheus との連携](./prometheus-monitoring) を参照してください。

### Auth0 による認証・ログインシステムの刷新\{#authentication-and-login-system-refactoring-with-auth0}

今回のリリースでは、Zilliz Cloud が Auth0 を使用して認証・ログインシステムを刷新しました。Zilliz Cloud は以下の 3 つのログイン方法をサポートしています。

- Eメールによる登録およびログイン。

- GitHub または Google 認証によるクイックログイン。

- エンタープライズ向け顧客のための SSO ログイン。詳細については、[Okta によるシングルサインオン](./single-sign-on) を参照してください。

### AWS Marketplace 無料トライアル\{#aws-marketplace-free-trial}

今回のリリースにより、Zilliz Cloud ユーザーは AWS Marketplace 無料トライアルを利用できるようになりました。これにより、大規模な購入を決定する前に、リスクなく Zilliz 製品を探索・評価できます。このトライアルではプラットフォームのコア機能にフルアクセスでき、ユーザーは自社アプリケーションとのパフォーマンス、スケーラビリティ、互換性を徹底的にテストできます。

[AWS Marketplace: Zilliz](https://aws.amazon.com/marketplace/seller-profile?id=4922a541-e428-480d-8e32-db4ee9a7f46e) から Zilliz サービスをご利用ください。
