# リリースノート（2023年4月6日）

Zilliz Cloud の最新アップデートを発表できることを嬉しく思います。今回のリリースでは、コスト見積もりのための料金計算ツール、データセキュリティ強化のためのデータバックアップおよび復元プロセス、グローバルユーザーのためのカスタマイズ可能なタイムゾーン設定、より良い整理のためのコレクション名変更ツール、無制限の使用のためのストレージクォータの廃止、および非アクティブなデータベースのためのクレジット節約の改善などが含まれています。

- 料金計算ツール

    新機能「料金計算ツール」のローンチを発表できることを嬉しく思います。この新機能は、ユーザーがコストを効果的に計画し、見積もることを支援するために設計されています。料金計算ツールを使用すると、ユーザーはCUタイプを簡単に選択し、エンティティ数とベクトル次元を入力して、推奨されるCUサイズとZilliz Cloudのコスト見積もりを取得できます。[こちらをクリック](https://zilliz.com/pricing#calculator)してお試しください。

    現在、料金計算ツールはベクトルデータのみをサポートしており、将来的にはスカラーデータも含めるよう機能を拡張する予定です。これにより、ユーザーにより正確なコスト見積もりを提供します。

- GCPでのバックアップと復元

    今回のリリースにより、プラットフォームはGoogle Cloud Platform（GCP）でのデータベースのバックアップと復元をサポートするようになりました。この最新リリースにより、ユーザーはGCP上でデータベースを簡単にバックアップおよび復元でき、データ復旧とビジネス継続性を確保できます。

    詳細については、[バックアップと復元](./backup-and-restore) を参照してください。

- カスタムタイムゾーン

    タイムゾーン設定のサポートを追加し、ユーザーがタイムゾーンの設定をカスタマイズし、すべてのデータのタイムスタンプを正確に保てるようにしました。

    詳細については、[タイムゾーンの管理](./organization-settings#manage-timezone) を参照してください。

- コレクション名の変更

    最新リリースに、データベースコレクションの名前を変更できる新機能が含まれることを発表できることを嬉しく思います。この機能は、ユーザーがデータベース構造をより良く管理し、新しいコレクションを作成してデータを移行することなく、必要な変更を行えるようにするために設計されています。

- ストレージクォータの廃止

    今回のリリースにより、プラットフォームからストレージクォータを廃止しました。これにより、ユーザーはストレージ制限を気にすることなく、アンロードされたコレクションにデータをインポートできるようになりました。データストレージに制限はありませんが、各データベースのロード容量はデータベースのサイズに依存します。適切なデータベースサイズを選択するために、料金計算ツールの使用を強く推奨します。

    さらに、データベースが事前に割り当てられたCUに収まらない場合のユーザーノーティフィケーションも改善しました。データベースが容量を超えた場合、ユーザーに通知が送信されます。これにより、ユーザーはデータのインポートが失敗した理由をより良く理解し、適切な対応を取ることができます。

- 非アクティブなデータベースのクレジット節約の改善

    非アクティブなデータベースの製品ロジックとリマインダーノーティフィケーションを最適化しました。ユーザーのデータベースが14日間連続して非アクティブな場合、無料クレジットを節約するために自動的にデータベースを停止します。データセキュリティは常に最優先事項であるため、非アクティブなデータベースからデータを削除することはありません。停止されたデータベースは、ユーザーがいつでも再開できます。また、この最適化を含めるよう、利用規約も更新しました。

- その他の改善

    - 請求のUIを改善しました。

    - CUタイプの名称を更新しました。「High パフォーマンス」は「パフォーマンス最適化済み」に、「Big データ」は「容量最適化済み」に名称変更されました。
