# リリースノート（2023年4月6日）

コスト見積もり用の料金計算ツール、データセキュリティを強化するデータのバックアップおよび復元プロセス、グローバルユーザー向けのカスタマイズ可能なタイムゾーン設定、より良い整理のためのコレクション名変更ツール、制限のない利用を可能にするストレージクォータの廃止、非アクティブなデータベース向けのクレジット節約機能の改善を含む、最新の Zilliz Cloud アップデートを発表できることを嬉しく思います。

- 料金計算ツール

    新機能である料金計算ツールのリリースをお知らせできることを嬉しく思います。この新機能は、ユーザーが効果的にコストを計画し、見積もるのに役立つよう設計されています。料金計算ツールでは、ユーザーは CU タイプを簡単に選択し、エンティティ数とベクトル次元数を入力することで、推奨される CU サイズと Zilliz Cloud のコスト見積もりを取得できます。試すには[こちらをクリックしてください](https://zilliz.com/pricing#calculator)。

    現在、料金計算ツールはベクトルデータのみをサポートしており、将来的にはスカラーデータも含めるよう機能を拡張し、ユーザーにさらに正確なコスト見積もりを提供する予定です。

- GCP でのバックアップと復元

    このリリースにより、当社のプラットフォームは Google Cloud Platform (GCP) 上でのデータベースのバックアップと復元をサポートするようになりました。この最新リリースにより、ユーザーは GCP 上でデータベースを簡単にバックアップおよび復元できるようになり、データ復旧と事業継続性を確保できます。

    詳細については、[Create Backup](./create-backup) および [Restore from Backup Files](./restore-from-backup-files) を参照してください。

- カスタムタイムゾーン

    タイムゾーン設定のサポートを追加し、ユーザーがタイムゾーン設定をカスタマイズして、すべてのデータに対して正確なタイムスタンプを確保できるようにしました。

    詳細については、[Manage Timezone](./organization-settings#manage-timezone) を参照してください。

- コレクション名変更

    最新リリースに、ユーザーがデータベースのコレクション名を変更できる新機能が含まれていることをお知らせできることを嬉しく思います。この機能は、ユーザーが新しいコレクションを作成してデータを移行しなくても、データベース構造をより適切に管理し、必要な変更を行えるよう設計されています。

- ストレージクォータの廃止

    このリリースにより、当社のプラットフォームからストレージクォータを廃止しました。これにより、ユーザーはストレージ制限を気にすることなく、ロードされていないコレクションにデータをインポートできるようになりました。データストレージ自体に制限はありませんが、各データベースのロード容量はデータベースのサイズに依存します。適切なデータベースサイズを選択するために、料金計算ツールを使用することを強く推奨します。

    さらに、事前割り当てされた CU にデータベースが収まらない場合のユーザー通知も改善しました。ユーザーのデータベースが容量を超えた場合、通知が送信されます。これにより、ユーザーはデータのインポートに失敗した理由をよりよく理解し、適切な対応を取ることができます。

- 非アクティブなデータベース向けのクレジット節約機能の改善

    非アクティブなデータベースに関する製品ロジックとリマインダー通知を最適化しました。ユーザーのデータベースが 14 日間連続で非アクティブな場合、無料クレジットの節約を支援するために、そのデータベースを自動的に停止します。データセキュリティは常に最優先事項であるため、非アクティブなデータベースからデータを削除することはありません。停止されたデータベースを持つユーザーは、いつでもそれを再開できます。さらに、この最適化を含めるように利用規約も更新しました。

- その他の改善

    - 課金の UI を改善しました。

    - CU タイプの名称を更新しました。現在、「High Performance」は「Performance-optimized」に、「Big Data」は「Capacity-optimized」に変更されています。
