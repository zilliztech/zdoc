# リリースノート（2023年4月6日）

コスト見積もり用の料金計算ツール、データセキュリティを強化するデータのバックアップおよびリストア機能、グローバルユーザー向けのカスタマイズ可能なタイムゾーン設定、より整理しやすくするためのコレクション名変更ツール、制限のない利用を可能にするストレージクォータの撤廃、非アクティブなデータベース向けのクレジット節約機能の改善を含む、最新の Zilliz Cloud アップデートを発表できることを嬉しく思います。

- 料金計算ツール

    新機能である料金計算ツールの提供開始を発表できることを嬉しく思います。この新機能は、ユーザーがコストを効果的に計画および見積もるのに役立つよう設計されています。料金計算ツールでは、ユーザーは CU タイプを簡単に選択し、エンティティ数とベクトル次元数を入力することで、推奨される CU サイズと Zilliz Cloud のコスト見積もりを取得できます。ぜひ[こちらをクリック](https://zilliz.com/pricing#calculator)してお試しください。

    現時点で料金計算ツールはベクトルデータのみに対応しており、今後はスカラーデータにも対応を拡張し、ユーザーにさらに正確なコスト見積もりを提供する予定です。

- GCP でのバックアップとリストア

    今回のリリースにより、当社プラットフォームは Google Cloud Platform (GCP) 上でのデータベースのバックアップおよびリストアをサポートするようになりました。この最新リリースにより、ユーザーは GCP 上でデータベースを簡単にバックアップおよびリストアでき、データ復旧と事業継続性を確保できます。

    詳細については、[Create Backup](./create-backup) および [Restore from Backup Files](./restore-from-backup-files) を参照してください。

- カスタムタイムゾーン

    タイムゾーン設定のサポートを追加し、ユーザーがタイムゾーンの設定をカスタマイズして、すべてのデータに正確なタイムスタンプを適用できるようになりました。

    詳細については、[Manage Timezone](./organization-settings#manage-timezone) を参照してください。

- コレクション名変更

    最新リリースに、データベースのコレクション名を変更できる新機能が含まれていることをお知らせします。この機能は、ユーザーがデータベース構造をより適切に管理し、新しいコレクションを作成してデータを移行することなく必要な変更を行えるように設計されています。

- ストレージクォータの撤廃

    今回のリリースにより、当社プラットフォームからストレージクォータを撤廃しました。これにより、ユーザーはストレージ制限を気にすることなく、アンロードされたコレクションにデータをインポートできるようになりました。データ保存量に制限はありませんが、各データベースのロード容量はそのデータベースのサイズに依存します。適切なデータベースサイズを選択するために、料金計算ツールの利用を強く推奨します。

    さらに、事前に割り当てられた CUs にデータベースが収まらない場合のユーザー通知も改善しました。データベースが容量を超えた場合、ユーザーに通知が送信されます。これにより、データのインポートに失敗した理由をよりよく理解し、適切な対応を取れるようになります。

- 非アクティブなデータベースのクレジット節約機能の改善

    非アクティブなデータベースに関する製品ロジックと通知リマインダーを最適化しました。ユーザーのデータベースが 14 日間連続で非アクティブだった場合、無料クレジットの節約を支援するために、そのデータベースを自動的に停止します。データセキュリティは常に最優先事項であるため、非アクティブなデータベースからデータを削除することはありません。停止されたデータベースは、ユーザーがいつでも再開できます。さらに、この最適化を反映するために利用規約も更新しました。

- その他の改善

    - Billing の UI を改善しました。

    - CU タイプの名称を更新しました - "High Performance" は "Performance-optimized" に、"Big Data" は "Capacity-optimized" に変更されました。
