# リリースノート（2023年4月6日）

コスト見積もり用の料金計算ツール、データセキュリティを強化するデータのバックアップと復元プロセス、グローバルユーザー向けのカスタマイズ可能なタイムゾーン設定、整理を容易にする collection 名変更ツール、制限のない利用を可能にするストレージクォータの撤廃、非アクティブなデータベースに対するクレジット節約の改善を含む、最新の Zilliz Cloud アップデートを発表できることを嬉しく思います。

- 料金計算ツール

    新機能である料金計算ツールの提供開始をお知らせできることを嬉しく思います。この新機能は、ユーザーがコストを効果的に計画し、見積もれるよう設計されています。料金計算ツールでは、ユーザーは CU タイプを簡単に選択し、entity 数と vector 次元数を入力することで、推奨される CU サイズと Zilliz Cloud のコスト見積もりを取得できます。お試しになるには[こちらをクリック](https://zilliz.com/pricing#calculator)してください。

    現在、料金計算ツールは vector データのみをサポートしており、今後は scalar データにも対応を拡張し、ユーザーにさらに正確なコスト見積もりを提供する予定です。

- GCP でのバックアップと復元

    今回のリリースにより、当社プラットフォームは Google Cloud Platform（GCP）でのデータベースのバックアップと復元をサポートするようになりました。この最新リリースにより、ユーザーは GCP 上でデータベースを簡単にバックアップおよび復元でき、データ復旧と事業継続性を確保できます。

    詳細については、[バックアップの作成](./create-backup)および[バックアップファイルからの復元](./restore-from-backup-files)を参照してください。

- カスタムタイムゾーン

    タイムゾーン設定のサポートを追加し、ユーザーがタイムゾーンの設定をカスタマイズして、すべてのデータに対して正確なタイムスタンプを確保できるようになりました。

    詳細については、[タイムゾーンの管理](./organization-settings#manage-timezone)を参照してください。

- Collection 名変更

    最新リリースに、データベース collection の名前を変更できる新機能が含まれていることをお知らせできることを嬉しく思います。この機能は、ユーザーが新しい collection を作成してデータを移行することなく、データベース構造をより適切に管理し、必要な変更を行えるようにするために設計されています。

- ストレージクォータの撤廃

    今回のリリースにより、当社プラットフォームからストレージクォータを撤廃しました。これにより、ユーザーはストレージ制限を気にすることなく、アンロードされた collection にデータをインポートできるようになりました。データストレージに制限はありませんが、各データベースのロード容量はデータベースのサイズに依存します。適切なデータベースサイズを選択するために、料金計算ツールの使用を強く推奨します。

    さらに、事前割り当てされた CU にデータベースが収まらない場合のユーザー通知も改善しました。データベースが容量を超えた場合、ユーザーは通知を受け取ります。これにより、データのインポートに失敗した理由をよりよく理解し、適切な対応を取れるようになります。

- 非アクティブなデータベースに対するクレジット節約の改善

    非アクティブなデータベースに関する製品ロジックと通知リマインダーを最適化しました。ユーザーのデータベースが 14 日間連続で非アクティブな場合、無料クレジットの節約を支援するために、そのユーザーのデータベースを自動的に停止します。データセキュリティは常に最優先事項であるため、非アクティブなデータベースからデータを削除することはありません。停止されたデータベースは、ユーザーがいつでも再開できます。さらに、この最適化を含めるよう利用規約も更新しました。

- その他の改善

    - Billing の UI を改善しました。

    - CU タイプの名称を更新しました。"High Performance" は "Performance-optimized" に、"Big Data" は "Capacity-optimized" に変更されました。
