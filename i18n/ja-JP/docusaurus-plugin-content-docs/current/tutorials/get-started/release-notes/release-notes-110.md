# リリースノート（2023年4月6日）

この度、Zilliz Cloudの最新アップデートを公開できることを大変嬉しく思います。今回のアップデートでは、コスト見積もり用の料金計算機、データのバックアップおよび復元機能による強化されたデータセキュリティ、グローバルユーザー向けのカスタマイズ可能なタイムゾーン設定、コレクション名変更ツールによる整理のしやすさ、ストレージクォータの撤廃による制限のない使用、および非アクティブなデータベースに対するクレジット節約機能の改善が含まれています。

- 料金計算機

    新機能「料金計算機」のリリースをお知らせします。この新機能は、ユーザーがコストを効果的に計画・見積もりできるように設計されています。料金計算機を使えば、CUタイプを選択し、エンティティ数とベクトル次元数を入力するだけで、推奨されるCUサイズおよびZilliz Cloudのコスト見積もりを簡単に取得できます。[こちらをクリック](https://zilliz.com/pricing#calculator)してお試しください。

    現在、当社の料金計算機はベクトルデータのみをサポートしていますが、将来的にはスカラーデータも含めた対応を拡張し、ユーザーの皆さまにさらに正確なコスト見積もりを提供する予定です。

- GCPでのバックアップおよび復元

    今回のリリースにより、Google Cloud Platform（GCP）上でデータベースのバックアップおよび復元が可能になりました。これにより、ユーザーはGCP上で簡単にデータベースをバックアップ・復元でき、データ復旧とビジネス継続性を確保できます。

    詳細については、[バックアップと復元](./backup-and-restore)をご参照ください。

- カスタムタイムゾーン

    タイムゾーン設定機能を追加しました。これにより、ユーザーは自身のタイムゾーン設定をカスタマイズでき、すべてのデータに正確なタイムスタンプが付与されます。

    詳細については、[タイムゾーンの管理](./organization-settings#manage-timezone)をご参照ください。

- コレクション名変更

    最新リリースでは、データベースのコレクション名を変更できる新機能を導入しました。この機能により、ユーザーは新しいコレクションを作成してデータを移行することなく、データベース構造をより適切に管理し、必要な変更を加えることができます。

- ストレージクォータの撤廃

    今回のリリースで、プラットフォームからストレージクォータを撤廃しました。これにより、ユーザーはアンロード済みのコレクションにデータをインポートする際に、ストレージ制限を気にする必要がなくなります。ただし、データストレージ自体には制限がないものの、各データベースのロード容量はそのデータベースのサイズに依存します。適切なデータベースサイズを選択するために、料金計算機のご利用を強く推奨します。

    また、事前に割り当てられたCUにデータベースが収まらない場合のユーザー通知も改善しました。データベースの容量が超過した際には通知が送信されるため、ユーザーはデータのインポートが失敗した理由をより明確に理解し、適切な対応を取ることができます。

- 非アクティブなデータベースにおけるクレジット節約機能の改善

    非アクティブなデータベースに関する製品ロジックおよびリマインダー通知を最適化しました。ユーザーのデータベースが14日間連続で非アクティブだった場合、無料クレジットを節約するために自動的にデータベースを停止します。データセキュリティは常に最優先事項であるため、非アクティブなデータベースからデータが削除されることはありません。停止されたデータベースは、ユーザーがいつでも再開できます。また、この最適化を反映するため、利用規約も更新しました。

- その他の改善点

    - 請求（請求）のUIを改善しました。
    - CUタイプの名称を更新しました。「High パフォーマンス」は「パフォーマンス最適化済み（パフォーマンス最適化済み）」に、「Big データ」は「容量最適化済み（容量最適化済み）」に変更されました。
