# リリースノート（2023年6月11日）

Zilliz Cloud のリリースは、ベクトルデータベース管理に新たな標準を打ち立てます。初心者にとってのユーザー体験を大幅に向上させ、より手頃で柔軟な料金オプションを提供し、チームのシームレスなコラボレーションを可能にし、柔軟なスキーマ管理を実現します。今回のアップデートの主な機能には、Serverless クラスター、多様な階層プラン、組織とコラボレーションのサポート、RBAC のサポート、パーティションキー、動的スキーマ、JSON 型のサポートが含まれます。この革新的なアップデートを今すぐお試しください！

## Milvus との互換性\{#milvus-compatibility}

このリリースは **Milvus 2.1.x** と互換性があります。

## Zilliz Cloud Serverless ベクトルデータベースサービスの開始\{#zilliz-cloud-serverless-vector-database-service-launch}

Zilliz Cloud の Serverless ベクトルデータベースサービスを開始したことをお知らせします。この新しいサービスは、当社の Dedicated クラスターソリューションと比べて、さらに手軽なベクトルデータ検索体験を提供します。

初期段階の企業を支援するため、Serverless サービスの一環として 2 つの無料コレクションを提供しています。各コレクションは 768 次元スケールで 500,000 個のベクトルを処理できる容量を備えており、大規模なインフラストラクチャを必要とせずに十分なデータ処理能力を提供します。当社の革新的な新機能をお試しいただき、今すぐデータ処理能力を向上させてください。[無料トライアル](./free-trials)。

## Zilliz Cloud のプラン階層：Starter、Standard、Enterprise、Self-hosted\{#zilliz-clouds-plan-tiers-starter-standard-enterprise-and-self-hosted}

Starter、Standard、Enterprise、Self-hosted という一連のプラン階層をご用意しています。各階層はコスト、サービス、セキュリティのバランスを考慮して設計されており、すべてのユーザーが自分のニーズに合ったプランを選択できるようになっています。Zilliz Cloud では、ビジネスの成長に合わせてベクトルデータベース管理を柔軟に拡張・進化させることができます。

- Starter プラン: 当社の Serverless インスタンスでフルマネージド型のベクトルデータベースを試すための最も簡単な方法です。最小限の構成で利用でき、GCP で利用可能です。

- Standard プラン: エンジニアが 5 人未満で、複雑なワークロードを扱うチーム向けに設計されています。高度なデータベース機能と構成を備えた Dedicated クラスターを提供し、優れたコスト効率も実現します。AWS と GCP の両方で利用可能です。

- Enterprise プラン: 高度なセキュリティとサポートを必要とする大規模組織向けに設計されています。すべての機能、高可用性、高度な構成を備えた Dedicated クラスターを提供し、AWS と GCP の両方で堅牢なデータベースソリューションを実現します。

- Self-hosted プラン: プライバシーと規制遵守を優先する企業に最適です。Virtual Private Cloud（VPC）内でセルフマネージド型のベクトルデータベースサービスを提供し、完全な制御を可能にします。プライバシーと規制遵守を優先する環境に適しています。

[料金ページで詳細をご覧ください。](https://zilliz.com/pricing)

## 組織、コラボレーション、RBAC\{#organization-collaboration-and-rbac}

Zilliz Cloud が高度な組織およびメンバー管理機能を提供するようになったことをお知らせします。これにより、複数のユーザーがクラスター、プロジェクト、組織などさまざまなレベルでシームレスにコラボレーションできます。

この重要なアップデートは、ロールベースアクセス制御（RBAC）の統合によって支えられており、特定のリソースに誰がアクセスできるかをきめ細かく制御できます。これによりセキュリティと柔軟性の両方が確保され、高度なデータ保護を維持しながら、チームがより効率的に連携できるようになります。

この機能強化により、プロジェクトへのアクセスをより細かく制御できるだけでなく、コラボレーションのプロセスも合理化され、チームがより安全で整理された環境でベクトルデータベースを管理しやすくなります。この機能を今すぐお試しいただき、Zilliz Cloud で新しいレベルのコラボレーション効率を体験してください。詳細については、Access Control Explained を参照してください。

## パーティションキー\{#partition-key}

Zilliz Cloud 2.0.0 では、パーティションキー機能が導入されています。この機能を使用すると、コレクションの作成時に特定のフィールドをパーティションキーとして指定できます。エンティティは、パーティションキーの値に基づいてパーティションに格納されます。

この機能は、クエリのフィルタリング時に特に役立ちます。パーティションキーフィールドに対する条件は、従来のスキャンベースのフィルタリング方法よりも大幅に高速に実行できるためです。基本的に、同じパーティションキーを持つエンティティは物理的にグループ化されるため、不要なスキャンを回避できます。

## 動的スキーマ\{#dynamic-schema}

Zilliz Cloud がバージョン 2.0.0 から動的スキーマをサポートするようになったことをお知らせします。この重要な機能強化により、多様なビジネス要件に対応する柔軟性が大幅に向上します。ユーザーは、事前に定義された静的スキーマに制限されることなく、動的に変化するフィールドを持つエンティティをコレクションに挿入できるようになりました。

上級ユーザー向けに、動的スキーマと静的スキーマを組み合わせたハイブリッドなコレクション作成アプローチを導入しました。これにより、ユーザーはスキーマ設計で「必須」フィールドを指定し、高度なインデックス最適化を有効にできます。一方、「オプション」フィールドは動的スキーマの仕組みによってサポートされます。この新しいアプローチは、スキーマの柔軟性を維持しながらクエリのパフォーマンスを向上させます。

Zilliz Cloud 2.0.0 でこの機能をお試しいただき、データベーススキーマの適応性が大幅に向上することをご確認ください。

詳細については、[Dynamic Field](./enable-dynamic-field) を参照してください。

## JSON 型のサポート\{#json-type-support}

最新のアップデートで、Zilliz Cloud に大きな機能強化を加えたことをお知らせします。それは、JSON データ管理と Approximate Nearest Neighbor（ANN）検索機能の統合です。

JSON（JavaScript Object Notation）は、今日のデータベース管理の世界で不可欠となっている重要なデータ交換フォーマットです。Zilliz Cloud で JSON サポートが導入されたことで、JSON データを簡単に保存・管理できるようになり、データ操作とクエリの無限の可能性が広がります。

真の力は、これを既存の ANN 検索機能と革新的に組み合わせた点にあります。この組み合わせにより、JSON データ構造の柔軟性と ANN 検索の精度を兼ね備えた複雑なクエリを実行できるようになり、データベースのクエリ機能が大幅に進歩します。

これら 2 つの強力なテクノロジーの相乗効果を 1 か所で体験し、データ管理とクエリタスクにおける新しいレベルの効率と精度を実現してください。Zilliz Cloud でデータベーステクノロジーの未来へ今すぐ踏み出しましょう。[この機能の詳細についてはこちら](./json-field-overview)。
