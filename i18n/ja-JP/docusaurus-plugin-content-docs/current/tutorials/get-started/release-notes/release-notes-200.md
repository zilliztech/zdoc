# リリースノート（2023年6月11日）

今回の Zilliz Cloud のリリースは、ベクトルデータベース管理において新たな基準を設定します。初心者にとってのユーザーエクスペリエンスが大幅に向上し、より手頃で柔軟な価格オプションが提供され、シームレスなチームコラボレーションが可能になり、柔軟なスキーマ管理も実現しました。今回のアップデートの主な機能には、サーバーレスクラスター、多様なティアプラン、組織とコラボレーションのサポート、RBAC サポート、パーティションキー、動的スキーマ、JSON 型サポートが含まれます。この画期的なアップデートを今すぐお試しください！

## Milvus 互換性\{#milvus-compatibility}

本リリースは **Milvus 2.1.x** と互換性があります。

## Zilliz Cloud サーバーレスベクトルデータベースサービスの開始\{#zilliz-cloud-serverless-vector-database-service-launch}

Zilliz Cloud のサーバーレスベクトルデータベースサービスの提供を開始したことをお知らせします。この新しいサービスは、専用クラスターのソリューションと比べて、さらに簡単にベクトルデータ検索を体験できるようになります。

初期段階のベンチャー企業を支援するため、サーバーレスサービスの一環として、2つの無料コレクションを提供しています。各コレクションは、768次元のスケールで50万ベクトルを処理できる容量を備えており、大規模なインフラストラクチャを必要とせずに十分なデータ処理能力を提供します。ぜひこの革新的な新機能をお試しください。[無料トライアル](./free-trials)

## Zilliz Cloud のプランティア：Starter、Standard、Enterprise、Self-hosted\{#zilliz-clouds-plan-tiers-starter-standard-enterprise-and-self-hosted}

Zilliz Cloud では、Starter、Standard、Enterprise、Self-hosted の4つのプランティアをご用意しています。各ティアはコスト、サービス、セキュリティのバランスを考慮して設計されており、すべてのユーザーがニーズに合ったプランを選べるようになっています。Zilliz Cloud を使えば、ビジネスの成長に合わせてベクトルデータベース管理を柔軟にスケーリングおよび進化させることができます。

- Starter Plan: サーバーレスインスタンスを使用して、完全マネージド型のベクトルデータベースを最も簡単に体験できます。最小限の設定で利用でき、GCP 上で提供されています。

- スタンダードプラン: 5名未満のエンジニアからなるチームや複雑なワークロード向けに設計されています。高度なデータベース機能と設定を備えた専用クラスターを提供し、優れたコスト効率を実現します。AWS および GCP の両方で利用可能です。

- Enterprise Plan: 高度なセキュリティとサポートを必要とする大規模組織向けに設計されています。フル機能、高可用性、高度な設定を備えた専用クラスターを提供し、AWS および GCP の両方で堅牢なデータベースソリューションを実現します。

- Self-hosted Plan: プライバシーと規制遵守を最優先する企業に最適です。お客様の Virtual プライベート Cloud (VPC) 内でセルフマネージド型のベクトルデータベースサービスを提供し、完全なコントロールを可能にします。プライバシーや規制遵守を重視する環境に適しています。

[価格ページで詳細をご確認ください。](https://zilliz.com/pricing)

## 組織、コラボレーション、および RBAC\{#organization-collaboration-and-rbac}

Zilliz Cloud が高度な組織およびメンバー管理機能を提供開始したことをお知らせします。これにより、クラスター、プロジェクト、組織といったさまざまなレベルで複数ユーザーがシームレスにコラボレーションできるようになります。

この大きなアップデートは、ロールベースアクセス制御（RBAC）の統合によって支えられています。これにより、特定のリソースへのアクセス権限をきめ細かく制御できます。セキュリティと柔軟性の両立を実現し、チームがより効率的に協力しながらも高いレベルのデータ保護を維持できるようになります。

この強化により、プロジェクトへのアクセス制御がより厳密になるだけでなく、コラボレーションプロセスも合理化され、チームがより安全で整理された環境でベクトルデータベースを管理しやすくなります。ぜひ今日からこの機能をお試しください。Zilliz Cloud で新たなレベルのコラボレーション効率を体験してください。詳細については、[アクセス制御](./access-control) を参照してください。

## パーティションキー\{#partition-key}

Zilliz Cloud 2.0.0 では、パーティションキー機能を導入しました。この機能により、コレクション作成時に特定のフィールドをパーティションキーとして指定できます。その後、エンティティはそのパーティションキーの値に基づいてパーティションに格納されます。

この機能はクエリフィルタリング時に特に有用です。パーティションキーのフィールドに対する条件は、従来のスキャンベースのフィルタリング手法と比べて非常に高速に実行できます。基本的に、同じパーティションキーを持つエンティティは物理的にグループ化されるため、不要なスキャンを回避できます。

## 動的スキーマ\{#dynamic-schema}

Zilliz Cloud がバージョン 2.0.0 から動的スキーマをサポートすることをお知らせします。この大きな強化により、多様なビジネス要件に対応する柔軟性が大幅に向上します。ユーザーは、事前に定義された静的スキーマに縛られることなく、動的に異なるフィールドを持つエンティティをコレクションに挿入できるようになります。

上級ユーザー向けには、動的スキーマと静的スキーマを組み合わせたハイブリッドアプローチによるコレクション作成を導入しました。これにより、スキーマ設計時に「必須」フィールドを指定して高度なインデックス最適化を有効化できます。一方、「任意」フィールドは動的スキーマメカニズムによってサポートされます。この新しいアプローチにより、スキーマの柔軟性を維持しながらクエリパフォーマンスを向上させます。

Zilliz Cloud 2.0.0 でこの機能を試し、データベーススキーマの適応性が大きく向上するのを体験してください。[この機能の詳細はこちら](./enable-dynamic-field)

## JSON 型サポート\{#json-type-support}

最新アップデートで Zilliz Cloud に大きな強化が加えられたことをお知らせします。JSON データ管理と近似最近傍（ANN）検索機能が統合されました。

JSON（JavaScript Object Notation）は、現代のデータベース管理において不可欠なデータ交換形式です。Zilliz Cloud で JSON サポートが導入されたことで、JSON データを簡単に保存・管理できるようになり、データ操作やクエリの可能性が無限に広がります。

真のパワーは、この機能と既存の ANN 検索機能を革新的に組み合わせた点にあります。この組み合わせにより、JSON データ構造の柔軟性と ANN 検索の精度を組み合わせた複雑なクエリを実行できるようになり、データベースクエリ機能が大きく前進します。

これら2つの強力なテクノロジーの相乗効果をぜひ体験し、データ管理およびクエリタスクの効率性と精度を新たなレベルへ引き上げてください。今すぐ Zilliz Cloud でデータベース技術の未来へ踏み出しましょう。[この機能の詳細はこちら](./use-json-fields)
