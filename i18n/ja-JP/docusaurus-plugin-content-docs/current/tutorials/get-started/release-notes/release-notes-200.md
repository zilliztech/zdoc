# リリースノート（2023年6月11日）

Zilliz Cloud のリリースは、ベクトルデータベース管理に新たな基準を打ち立てます。初心者向けのユーザー体験を大幅に向上させ、より手頃で柔軟な料金オプションを提供し、シームレスなチームコラボレーションを可能にし、柔軟なスキーマ管理を提供します。今回のアップデートの主な機能には、Serverless クラスター、多様な階層プラン、組織とコラボレーションのサポート、RBAC サポート、Partition Key、動的スキーマ、JSON 型のサポートが含まれます。この画期的なアップデートをぜひ今すぐお試しください。

## Milvus 互換性\{#milvus-compatibility}

このリリースは **Milvus 2.1.x** と互換性があります。

## Zilliz Cloud Serverless ベクトルデータベースサービスの提供開始\{#zilliz-cloud-serverless-vector-database-service-launch}

Zilliz Cloud の Serverless ベクトルデータベースサービスの提供開始を発表できることを嬉しく思います。この新しいサービスは、当社の専用クラスターソリューションと比べて、さらに手軽なベクトルデータ検索体験を提供します。

初期段階のベンチャーを支援するため、Serverless Service の一環として無料のコレクションを 2 つ提供しています。各コレクションは、768 次元のスケールで 500,000 個のベクトルを処理できる容量を備えており、大規模なインフラを必要とせずに十分なデータ処理能力を提供します。この革新的な新機能を試して、今すぐデータ処理能力を高めましょう。[無料トライアル](./free-trials)。

## Zilliz Cloud のプラン階層: Starter、Standard、Enterprise、Self-hosted\{#zilliz-clouds-plan-tiers-starter-standard-enterprise-and-self-hosted}

Starter、Standard、Enterprise、Self-hosted という幅広いプラン階層を提供できることを嬉しく思います。各階層は、コスト、サービス、セキュリティの考慮事項のバランスを取るように設計されており、すべてのユーザーがニーズに合ったプランを利用できるようになっています。Zilliz Cloud では、ビジネスの成長に合わせてベクトルデータベース管理を柔軟に拡張し、進化させることができます。

- Starter Plan: Serverless インスタンスでフルマネージドのベクトルデータベースを体験する最もシンプルな方法です。必要な構成は最小限で、GCP で利用できます。

- Standard Plan: エンジニアが 5 人未満のチームと複雑なワークロード向けに設計されています。高度なデータベース機能と構成を備えた専用クラスターを提供し、優れたコスト効率も実現します。AWS と GCP の両方で利用できます。

- Enterprise Plan: 高度なセキュリティとサポートを必要とする大規模組織向けに設計されています。フル機能、高可用性、高度な構成を備えた専用クラスターを提供し、AWS と GCP の両方で堅牢なデータベースソリューションを実現します。

- Self-hosted Plan: プライバシーと規制順守を重視する企業に最適です。Virtual Private Cloud（VPC）内でセルフマネージドのベクトルデータベースサービスを提供し、完全な制御を可能にします。プライバシーと規制順守を優先する環境に適しています。

[料金ページで詳細をご確認ください。](https://zilliz.com/pricing)

## 組織、コラボレーション、RBAC\{#organization-collaboration-and-rbac}

Zilliz Cloud が、洗練された組織およびメンバー管理機能を提供するようになったことを発表できることを嬉しく思います。これにより、複数のユーザーがクラスター、プロジェクト、組織など、さまざまなレベルでシームレスにコラボレーションできるようになります。

この大きなアップデートは、Role-Based Access Control（RBAC）の統合によって支えられており、特定のリソースにアクセスできるユーザーをきめ細かく制御できます。これにより、セキュリティと柔軟性の両方が確保され、高いデータ保護を維持しながらチームがより効率的に共同作業を行えるようになります。

この機能強化は、プロジェクトアクセスに対するより細かな制御を提供するだけでなく、コラボレーションのプロセスも効率化し、チームがより安全で整理された環境でベクトルデータベースを管理しやすくします。今すぐこの機能を活用して、Zilliz Cloud による新たなレベルのコラボレーション効率を体験してください。詳細については、[アクセス制御の概要](./access-control-overview) を参照してください。

## Partition Key\{#partition-key}

Zilliz Cloud 2.0.0 では Partition Key 機能が導入されました。この機能を使用すると、コレクションの作成時に特定のフィールドをパーティションキーとして指定できます。エンティティは、パーティションキーの値に基づいてパーティションに格納されます。

この機能は、クエリのフィルタリング時に特に役立ちます。パーティションキーフィールドに対する条件は、従来のスキャンベースのフィルタリング方法よりも大幅に高速に実行できるためです。基本的に、同じパーティションキーを持つエンティティは物理的にまとめて配置されるため、不要なスキャンを回避できます。

## 動的スキーマ\{#dynamic-schema}

Zilliz Cloud がバージョン 2.0.0 から動的スキーマをサポートするようになったことを発表できることを嬉しく思います。この大幅な機能強化により、多様なビジネス要件に対応する柔軟性が大きく向上します。ユーザーは、事前定義された静的なスキーマに制限されることなく、動的に変化するフィールドを持つエンティティをコレクションに挿入できるようになりました。

上級ユーザー向けには、動的スキーマと静的スキーマを組み合わせたハイブリッドなコレクション作成アプローチを導入しました。これにより、ユーザーはスキーマ設計で「required」フィールドを指定し、高度なインデックス最適化を有効にできます。一方、「optional」フィールドは動的スキーマの仕組みによってサポートされます。この新しいアプローチは、スキーマの柔軟性を維持しながらクエリパフォーマンスを向上させます。

Zilliz Cloud 2.0.0 でこの機能をお試しいただき、データベーススキーマの適応性が大きく向上することをご確認ください。

詳細については、[Dynamic Field](./enable-dynamic-field) を参照してください。

## JSON 型のサポート\{#json-type-support}

最新のアップデートにおける Zilliz Cloud の大きな機能強化として、JSON データ管理と Approximate Nearest Neighbor（ANN）Search 機能の統合を発表できることを嬉しく思います。

JSON（JavaScript Object Notation）は、今日のデータベース管理の世界で不可欠となっている重要なデータ交換形式です。Zilliz Cloud で JSON サポートが導入されたことで、JSON データを簡単に保存および管理できるようになり、データ操作とクエリの可能性が大きく広がります。

その真の力は、これと既存の ANN Search 機能との革新的な組み合わせにあります。この組み合わせにより、JSON データ構造の柔軟性と ANN Search の精度を兼ね備えた複雑なクエリを実行できるようになり、データベースのクエリ機能が大きく前進します。

1 か所でこれら 2 つの強力なテクノロジーの相乗効果を体験し、データ管理とクエリ作業における効率性と精度を新たなレベルに引き上げてください。今すぐ Zilliz Cloud とともにデータベーステクノロジーの未来へ踏み出しましょう。[JSON フィールドの概要](./json-field-overview)。
