# リリースノート (2023年6月11日)

Zilliz Cloud のリリースにより、ベクトルデータベース管理の新たな基準が確立されました。初心者のユーザー体験を大幅に向上させ、より手頃で柔軟な価格オプションを提供し、シームレスなチームコラボレーションを実現し、柔軟なスキーマ管理を提供します。このアップデートの主な機能には、サーバーレスクラスター、多様なティアプラン、組織およびコラボレーションのサポート、RBAC サポート、パーティションキー、ダイナミックスキーマ、および JSON 型のサポートが含まれます。ぜひ、この画期的なアップデートをお試しください！

## Milvus 互換性\{#milvus-compatibility}

このリリースは **Milvus 2.1.x** と互換性があります。

## Zilliz Cloud サーバーレスベクトルデータベースサービスのローンチ\{#zilliz-cloud-serverless-vector-database-service-launch}

Zilliz Cloud のサーバーレスベクトルデータベースサービスのローンチを発表いたします。この新しいサービスは、専用クラスターソリューションと比較して、さらに手軽なベクトルデータ検索体験を提供します。

初期段階のベンチャーを支援するため、サーバーレスサービスの一環として2つの無料コレクションを提供しています。各コレクションは、768次元スケールで500,000ベクトルを処理できる容量を持ち、大規模なインフラストラクチャを必要とせずに実質的なデータ処理能力を提供します。革新的な新機能をお試しの上、データ処理能力を向上させてください。[無料トライアル](./free-trials)

## Zilliz Cloud のプラン階層: Starter、Standard、Enterprise、および Self-hosted\{#zilliz-clouds-plan-tiers-starter-standard-enterprise-and-self-hosted}

Starter、Standard、Enterprise、および Self-hosted の各プラン階層を提供できることを嬉しく思います。各階層はコスト、サービス、およびセキュリティの考慮事項のバランスを取るように設計されており、すべてのユーザーがニーズを満たすプランを持てるようにしています。Zilliz Cloud では、ビジネスの成長に合わせてベクトルデータベース管理をスケールおよび進化させる柔軟性を持っています。

- Starter Plan: サーバーレスインスタンスで完全に管理されたベクトルデータベースを体験する最もシンプルな方法です。最小限の構成が必要で、GCP で利用可能です。

- スタンダードプラン: 5名未満のエンジニアチームと複雑なワークロード向けに設計されています。専用クラスターと高度なデータベース機能および構成、優れたコスト効率を提供します。AWS と GCP の両方で利用可能です。

- Enterprise Plan: 高度なセキュリティとサポートニーズを持つ大規模組織向けに設計されています。専用クラスターとフル機能、高可用性、高度な構成を提供し、AWS と GCP の両方で堅牢なデータベースソリューションを提供します。

- Self-hosted Plan: プライバシーと規制順守を優先する企業に最適です。仮想プライベートクラウド（VPC）内で自己管理型のベクトルデータベースサービスを提供し、完全なコントロールを可能にします。プライバシーと規制順守を優先する環境に適しています。

[価格ページで詳細を確認する](https://zilliz.com/pricing)

## 組織、コラボレーション、および RBAC\{#organization-collaboration-and-rbac}

Zilliz Cloud が、高度な組織およびメンバー管理機能を提供することを発表いたします。これにより、複数のユーザーが Cluster、Project、および Organization を含むさまざまなレベルでシームレスにコラボレーションできます。

この主要なアップデートは、ロールベースアクセス制御（RBAC）の統合によってサポートされています。これにより、特定のリソースに誰がアクセスできるかを細かく制御できます。これにより、セキュリティと柔軟性の両方が確保され、チームが高度なデータ保護を維持しながらより効率的に協力できるようになります。

この強化により、プロジェクトアクセスに対するより大きなコントロールが提供されるだけでなく、コラボレーションプロセスが効率化され、チームがより安全で組織的な環境でベクトルデータベースを管理しやすくなります。ぜひこの機能を今すぐお試しの上、Zilliz Cloud での新たなコラボレーション効率のレベルを体験してください。詳細については、[アクセス制御](./access-control) を参照してください。

## パーティションキー\{#partition-key}

Zilliz Cloud 2.0.0 でパーティションキー機能が導入されました。この機能により、コレクションの作成時に特定のフィールドをパーティションキーとして指定できます。その後、エンティティはパーティションキーの値に基づいてパーティションに格納されます。

この機能は、クエリフィルタリング時に特に有用です。パーティションキーフィールドに対する条件は、従来のスキャンベースのフィルタリング方法よりも大幅に高速に実行できます。基本的に、同じパーティションキーを持つエンティティは物理的にグループ化されるため、不要なスキャンを回避できます。

## ダイナミックスキーマ\{#dynamic-schema}

Zilliz Cloud がバージョン 2.0.0 からダイナミックスキーマをサポートすることを発表いたします。この主要な強化により、多様なビジネス要件に対応する柔軟性が大幅に向上します。ユーザーは、事前に定義された静的スキーマに制限されることなく、動的に異なるフィールドを持つエンティティをコレクションに挿入できるようになりました。

上級ユーザー向けに、ダイナミックスキーマとスタティックスキーマを組み合わせたハイブリッドアプローチをコレクション作成に組み込みました。これにより、ユーザーはスキーマ設計で「必須」フィールドを指定し、高度なインデックス最適化を有効化できます。一方、「オプション」フィールドはダイナミックスキーマメカニズムによってサポートされます。この新しいアプローチにより、スキーマの柔軟性を維持しながらクエリパフォーマンスが向上します。

Zilliz Cloud 2.0.0 でこの機能を探索し、データベーススキーマの適応性の大幅な向上を実感してください。[この機能の詳細](./enable-dynamic-field)

## JSON 型のサポート\{#json-type-support}

最新のアップデートにおける Zilliz Cloud の主要な強化事項、JSON データ管理と近似最近傍（ANN）検索機能の統合を発表いたします。

JSON（JavaScript Object Notation）は、今日のデータベース管理の世界で不可欠となっている重要なデータ交換フォーマットです。Zilliz Cloud での JSON サポートの導入により、JSON データの保存と管理が容易になり、データ操作とクエリの可能性が無限に広がります。

真の力は、既存の ANN 検索機能との革新的な組み合わせにあります。この組み合わせにより、JSON データ構造の柔軟性と ANN 検索の精度を組み合わせた複雑なクエリを実行できるようになり、データベースクエリ機能の大幅な飛躍を提供します。

この2つの強力なテクノロジーの相乗効果を一箇所で体験し、データ管理およびクエリタスクの効率と精度の新たなレベルを解き放ちましょう。今日、Zilliz Cloud でデータベーステクノロジーの未来に足を踏み入れてください。[この機能の詳細](./use-json-fields)
