# リリースノート（2023年6月11日）

Zilliz Cloud のリリースは、ベクトルデータベース管理に新たな基準を打ち立てます。初心者のユーザー体験を大幅に向上させ、より手頃で柔軟な価格オプションを提供し、シームレスなチームコラボレーションを可能にし、柔軟なスキーマ管理を実現します。この更新の主な機能には、サーバーレスクラスター、多様なティアプラン、組織とコラボレーションのサポート、RBAC サポート、パーティションキー、動的スキーマ、JSON 型サポートが含まれます。今すぐこの画期的なアップデートをお試しください！

## Milvus Compatibility\{#milvus-compatibility}

このリリースは **Milvus 2.1.x** と互換性があります。

## Zilliz Cloud Serverless Vector Database Service Launch\{#zilliz-cloud-serverless-vector-database-service-launch}

Zilliz Cloud のサーバーレスベクトルデータベースサービスの提供開始を発表できることを嬉しく思います。この新しいサービスは、専用クラスターソリューションと比較して、さらに手軽なベクトルデータ検索体験を提供します。

初期段階のベンチャー企業を支援するため、サーバーレスサービスの一環として 2 つの無料コレクションを提供しています。各コレクションは 768 次元スケールで 500,000 個のベクトルを処理できる容量を備えており、大規模なインフラを必要とせずに十分なデータ処理能力を提供します。この革新的な新機能を試して、今すぐデータ処理能力を向上させましょう。[無料トライアル](./free-trials)。

## Zilliz Cloud's Plan Tiers: Starter, Standard, Enterprise, and Self-hosted\{#zilliz-clouds-plan-tiers-starter-standard-enterprise-and-self-hosted}

Starter、Standard、Enterprise、Self-hosted の各種プランティアを提供できることを嬉しく思います。各ティアは、コスト、サービス、セキュリティの観点のバランスを取るように設計されており、すべてのユーザーが自身のニーズに合ったプランを利用できるようになっています。Zilliz Cloud では、ビジネスの成長に合わせて柔軟にベクトルデータベース管理を拡張・進化させることができます。

- Starter Plan: サーバーレスインスタンスでフルマネージドなベクトルデータベースを体験する最もシンプルな方法です。必要な設定は最小限で、GCP で利用できます。

- Standard Plan: 5 人未満のエンジニアチームと複雑なワークロード向けに設計されています。高度なデータベース機能と設定を備えた専用クラスターを提供し、優れたコスト効率も実現します。AWS と GCP の両方で利用できます。

- Enterprise Plan: 高度なセキュリティとサポートを必要とする大規模な組織向けに設計されています。フル機能、高可用性、高度な設定を備えた専用クラスターを提供し、AWS と GCP の両方で堅牢なデータベースソリューションを実現します。

- Self-hosted Plan: プライバシーと規制遵守を重視する企業に最適です。Virtual Private Cloud (VPC) 内で自己管理型のベクトルデータベースサービスを提供し、完全な制御を実現します。プライバシーと規制遵守を優先する環境に適しています。

[料金ページで詳細をご覧ください。](https://zilliz.com/pricing)

## Organization, Collaboration, and RBAC\{#organization-collaboration-and-rbac}

Zilliz Cloud が高度な組織およびメンバー管理機能を提供するようになったことを発表できることを嬉しく思います。これにより、複数のユーザーが Cluster、Project、Organization などさまざまなレベルでシームレスに共同作業できるようになります。

この大規模アップデートは、Role-Based Access Control (RBAC) の統合によって支えられており、特定のリソースに誰がアクセスできるかをきめ細かく制御できます。これにより、セキュリティと柔軟性の両方が確保され、高度なデータ保護を維持しながら、チームがより効率的に共同作業できるようになります。

この強化により、プロジェクトアクセスに対するより大きな制御が可能になるだけでなく、コラボレーションのプロセスも効率化され、チームがより安全で整理された環境でベクトルデータベースを管理しやすくなります。今すぐこの機能を活用し、Zilliz Cloud で新たなレベルの共同作業効率を体験してください。詳細については、[Access Control Explained](./access-control-overview) を参照してください。

## Partition Key\{#partition-key}

Zilliz Cloud 2.0.0 では、パーティションキー機能が導入されました。この機能により、コレクション作成時に特定のフィールドをパーティションキーとして指定できます。すると、エンティティはパーティションキーの値に基づいてパーティションに格納されます。

この機能は、クエリのフィルタリング時に特に有用で、パーティションキーフィールドに対する条件は、従来のスキャンベースのフィルタリング方法よりも大幅に高速に実行できます。つまり、同じパーティションキーを持つエンティティは物理的にまとめてグループ化されるため、不要なスキャンを回避できます。

## Dynamic Schema\{#dynamic-schema}

Zilliz Cloud がバージョン 2.0.0 から動的スキーマをサポートするようになったことを発表できることを嬉しく思います。この大きな強化により、多様なビジネス要件に対応する柔軟性が大幅に向上します。ユーザーは、事前定義された静的スキーマに制限されることなく、動的に異なるフィールドを持つエンティティをコレクションに挿入できるようになりました。

上級ユーザー向けに、動的スキーマと静的スキーマを組み合わせた、コレクション作成のハイブリッドアプローチを取り入れました。これにより、ユーザーはスキーマ設計内で「必須」フィールドを指定し、高度なインデックス最適化を有効にできます。一方で、「任意」フィールドは動的スキーマのメカニズムでサポートされます。この新しいアプローチは、スキーマの柔軟性を維持しながらクエリ性能を向上させます。

Zilliz Cloud 2.0.0 でこの機能を試し、データベーススキーマの適応性が大きく向上することを実感してください。

詳細については、[Dynamic Field](./enable-dynamic-field) を参照してください。

## JSON Type Support\{#json-type-support}

最新アップデートにおいて、Zilliz Cloud への大きな機能強化として JSON データ管理と Approximate Nearest Neighbor (ANN) Search 機能の統合を発表できることを嬉しく思います。

JSON（JavaScript Object Notation）は、今日のデータベース管理の世界で不可欠となっている重要なデータ交換フォーマットです。Zilliz Cloud に JSON サポートが導入されたことで、JSON データを簡単に保存・管理できるようになり、データ操作やクエリにおける可能性が大きく広がります。

真価は、これを既存の ANN Search 機能と革新的に組み合わせた点にあります。この組み合わせにより、JSON データ構造の柔軟性と ANN Search の精度を兼ね備えた複雑なクエリを実行できるようになり、データベースのクエリ機能が大きく前進します。

これら 2 つの強力な技術がもたらす相乗効果を活用し、データ管理とクエリタスクにおける効率と精度を新たなレベルへ引き上げてください。今すぐ Zilliz Cloud とともにデータベース技術の未来へ踏み出しましょう。[この機能の詳細はこちら](./json-field-overview)。
