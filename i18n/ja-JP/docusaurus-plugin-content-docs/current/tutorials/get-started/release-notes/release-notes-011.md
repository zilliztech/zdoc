# リリースノート（2023年2月13日）

Zilliz Cloud の大幅なアップデートの一般提供を発表いたします。このリリースでは、Eメール通知と初心者向けのインラインガイドが追加されました。

- Eメール通知

    このリリースでは、Eメール通知機能が強化されました。以下のイベントでEメール通知を受信します。

    - アカウントの認証、停止、再開など

    - クレジット残高と有効期限

    - 請求と支払い

    - データベースの非アクティブ状態

    - 今後のシステムメンテナンス

    - 購読済みリソースのアラート

    - ユーザーフィードバックの受領確認

- 初心者向けインラインガイド

    このリリースでは、初心者向けのインラインガイドが大幅に改善され、迅速なオンボーディングが可能になりました。これで、事前知識がなくても5分以内にオンラインチュートリアルを完了できます。[ぜひお試しください！](https://cloud.zilliz.com/signup)
