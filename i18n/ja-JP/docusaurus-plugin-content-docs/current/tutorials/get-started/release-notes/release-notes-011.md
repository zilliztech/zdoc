# リリースノート（2023年2月13日）

Zilliz Cloud の重要なアップデートを正式にリリースできることを嬉しく思います。今回のリリースでは、Eメール通知機能と初心者向けのインラインガイドが追加されました。

- Eメール通知

    今回のリリースでは、Eメール通知機能が強化されています。以下のイベントが発生した際に、Eメール通知を受け取るようになります。

    - アカウントの検証、停止、再有効化など

    - クレジット残高および有効期限

    - 請求および支払い

    - データベースの非アクティブ状態

    - 今後のシステムメンテナンス

    - 購読済みリソースのアラート

    - ユーザーフィードバックの受領確認

- 初心者向けのインラインガイド

    今回のリリースでは、初心者向けのインラインガイドが大幅に改善され、迅速なオンボーディングが可能になりました。事前の知識がなくても、5分以内でオンラインチュートリアルを完了できます。[ぜひお試しください！](https://cloud.zilliz.com/signup)
