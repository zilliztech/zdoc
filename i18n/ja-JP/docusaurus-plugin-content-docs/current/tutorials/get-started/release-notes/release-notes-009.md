# リリースノート（2022年12月5日）

Zilliz Cloud の大規模アップデートを正式にリリースできることを嬉しく思います。今回のリリースでは、Zilliz Cloud サービス向けの新しいコンソールを導入し、新たなクラウドリージョンをサポートするとともに、プライベートリンク経由での安全なクラスターアクセスが可能になりました。

- Zilliz Cloud サービス向けの新しい UI

    今回のリリースでは、Zilliz Cloud 向けの新しい UI を導入しました。まったく新しい UI にはツリー型のナビゲーション構造を採用しており、より直感的な操作が可能です。すべての機能は以下の 5 つのカテゴリに整理されています。

    これらの機能はすべて、Zilliz Cloud 上で 90 日間の無料トライアルが利用可能です。[今すぐ試す！](https://cloud.zilliz.com/)

- AWS リージョン **US-East-2** をサポート

    Zilliz Cloud が新しい AWS リージョン **US-East-2** へのサービス展開をサポート開始したことをお知らせします。現在サポートしているリージョンは、AWS **US-West-2** および **US-East-2** です。

- プライベートリンク

    プライベートリンクにより、アプリケーションからデータベースへのプライベート接続が実現されます。このプライベートリンクのソリューションは、Zilliz Cloud サービスに対してプライベートで、より安全かつ効率的な接続性を必要とするニーズに対応します。

    プライベートリンクを使用してデータベース接続を設定するには、VPC エンドポイントを Zilliz Cloud に登録し、プライベートリンクを作成してそのリンクをエンドポイントの DNS 名にマッピングする必要があります。

    詳細については、[プライベートリンクの設定](./setup-a-private-link) を参照してください。

- 大容量ファイルからのデータインポート

    Zilliz Cloud が大容量ファイルからのデータインポートをサポート開始したことをお知らせします。最大 512 MB のファイルからコレクションへ一括でデータを挿入できます。ファイルの保存先は S3 バケットまたはローカルディスクのいずれかです。

    詳細については、[データインポート](./data-import) を参照してください。
