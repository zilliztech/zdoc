        ## Autoscalingのアップグレード\{#autoscaling-upgrade}

        **Zilliz Cloudのautoscaling機能に大幅なアップグレードを導入します。** これにより、より優れた自動化されたリソース管理エクスペリエンスを提供します。主な改善点は以下のとおりです。

        - **インテリジェントなAutoscaling:** スケールアップのための容量しきい値を手動で設定する必要がなくなります。当社のシステムは、リアルタイムのワークロード需要に基づいて、最適なパフォーマンスとリソース使用率を自動的に保証します。

        - **自動スケールダウンのサポート:** 多くのユーザーから要望のあった機能がついに登場します！新しいautoscalingでは、負荷が低い期間に自動的にスケールダウンし、手動介入なしにコストを最適化します。

        - **簡素化された設定:** 最小および最大CUサイズを設定するだけでよくなります。Zilliz Cloudは、これらの境界内で自動的にスケーリングを管理し、可用性とリソース使用率のバランスを最適化します。

        ## 監査ログのGA\{#audit-log-ga}

        今回のリリースでは、**監査ログ**（監査ログ）の**GA**（general availability）を発表できることを嬉しく思います。これにより、**3つのクラウドプロバイダーすべて**（AWS、GCP、Azure）でホストされているクラスターがサポートされます。

        VectorDB監査ログは、クラスター内でのユーザー活動の詳細な記録を提供し、**セキュリティの強化、コンプライアンスの確保、問題のトラブルシューティング**をより効率的に行えるようにします。クエリ／検索からデータ管理操作、接続イベントからユーザーまたはロールの変更まで、すべての操作を完全に可視化することで、監査ログは**データアクセスの監視**、異常な動作の検出、**エンタープライズガバナンスおよびコンプライアンス要件の満たし**を可能にします。

        GA以降、監査ログは**有料機能**となります。ご利用になるには、**Enterprise Plan**の下で**専用クラスター**を選択してください。

        - 使用方法の詳細については、[VectorDB 監査ログ User Guide](./audit-logs)をご覧ください。

        - 料金情報については、[Pricing Guide](./understand-cost)をご覧ください。

        ## SSOエクスペリエンスの改善\{#improved-sso-experience}

        今回のリリースでは、Zilliz CloudにおけるSSO設定プロセスを改善し、設定をよりシンプルかつ迅速に、そしてエラーが起こりにくくしました。

        **ハイライト:**

        - **IdP固有のフロー**: **Okta**（OIDC、SAML 2.0）、**Microsoft Entra**（SAML 2.0）、**Google Workspace**（SAML 2.0）向けのカスタマイズされたガイダンスを、コンソールおよび[ドキュメント](./single-sign-on)で提供。

        - **UXの向上**: より明確なフィールドマッピングと証明書アップロード時のバリデーションにより、設定ミスを防止。

        - **強化されたドキュメント**: **視覚的なIdP固有の例**を含み、Zilliz UIとIdP管理コンソール間の頻繁な切り替えを減らします。

        ## 機能強化\{#enhancements}

        - **SDK**（Python、Java）を使用して、ステージの**ライフサイクル全体を管理**できるようになりました。SDK経由でステージを作成した後、ファイルのアップロードやワークフローの処理をシームレスに行えるため、開発がよりスムーズで効率的になります。

        - **GUI**から直接**Parquet形式のローカルファイルをインポート**できるようになり、サポートされるフォーマットがJSONに加えてさらに拡張されました。これにより、大規模データセットの取り扱いが容易になり、データオンボーディングプロセスが合理化されます。

        - **Milvusバックアップファイルからの移行**において、特定の**データベースとコレクション**を選択できるようになりました。これにより、オンプレミスのMilvusからクラウドへのデータ移行時に、より柔軟かつ正確な制御が可能になります。

        - Zilliz GUI上でコレクションに関連付けられた**すべてのエイリアスを表示**できるようになり、エイリアスの管理と使用状況の追跡が容易になります。

        - ZillizのTerraform ProviderがBYOCインスタンスの管理をサポートしました。Terraformを使用して、BYOCプロジェクト内のインスタンスの作成、更新、削除が可能になります。

        - 利用状況の詳細をCSV形式でエクスポートできるようになり、データの分析およびアーカイブがより簡単になるよう、ユーザーエクスペリエンスも改善されました。

        - 請求プロファイルのメールアドレスが請求通知を受信できるようになり、財務チームが最新情報を常に把握できるようになります。
