# リリースノート (2023年1月10日)

Zilliz Cloud の大幅なアップデートの一般提供を発表いたします。本リリースでは、データプレビュー機能と、コンソール上のコレクションに簡単にインポートできるデモデータセットが追加されました。

- データプレビュー

    本リリースでは、Zilliz Cloud にデータプレビュー機能が提供されています。各コレクションページに **データプレビュー** 機能タブがあります。プレビューテーブルでは、コレクション内のサンプリングされたエンティティのすべての値を表示できるため、データの確認が容易になります。

    データプレビュー機能に加えて、プレビューテーブル内の任意のベクトルを選択してクエリベクトルとして使用できます。これにより、コレクション内の近傍データを迅速に確認できます。

- デモデータセット

    Zilliz Cloud では、ベクトルデータベースの機能に慣れていない初心者向けにデモデータセットを提供しています。デモデータセットは Kaggle のデータセットから派生しています。著名な出版物に掲載された2020年1月から2020年8月までの5,000件以上の記事の詳細が含まれています。

    これで、データ準備の手間をかけることなく、ベクトルデータベースの全機能セットを簡単に体験できます。[ぜひお試しください！](https://cloud.zilliz.com/signup)
