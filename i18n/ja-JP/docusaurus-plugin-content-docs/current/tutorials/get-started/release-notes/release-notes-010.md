# リリースノート（2023年1月10日）

Zilliz Cloud の大規模アップデートの一般提供開始をお知らせします。このリリースでは、データプレビュー機能に加え、コンソール上でコレクションに簡単にインポートできるデモデータセットが追加されました。

- データプレビュー

    このリリースでは、Zilliz Cloud がデータプレビュー機能を提供します。各コレクションページにある **Data Preview** 機能タブから確認できます。プレビューテーブルでは、コレクション内のサンプリングされたエンティティ群のすべての値を表示できるため、データを簡単に検証できます。

    データプレビュー機能に加えて、プレビューテーブル内の任意のベクトルを選択し、それをクエリベクトルとして使用できます。これにより、コレクション内の近傍データをすばやく検証できます。

- デモデータセット

    Zilliz Cloud は、初心者がベクトルデータベースの機能に慣れるのに役立つデモデータセットを提供するようになりました。このデモデータセットは Kaggle のデータセットをもとにしています。著名な出版物に 2020 年 1 月から 2020 年 8 月までの間に掲載された 5,000 件を超える記事の詳細が含まれています。

    これで、データ準備のための追加作業なしに、ベクトルデータベースの機能一式を簡単に体験できます。[ぜひお試しください！](https://cloud.zilliz.com/signup)
