# リリースノート（2023年1月10日）

Zilliz Cloud の大規模アップデートを正式にリリースできることを嬉しく思います。今回のリリースでは、データプレビュー機能とデモデータセットが追加され、コンソール上で簡単にコレクションにインポートできるようになりました。

- データ preview

    今回のリリースでは、Zilliz Cloud にデータプレビュー機能が追加されました。各コレクションページに **データプレビュー** タブが表示されます。このプレビューテーブルでは、コレクション内のサンプリングされたエンティティのすべての値を確認でき、データの検証が容易になります。

    データプレビュー機能に加えて、プレビューテーブル内の任意のベクトルを選択し、それをクエリベクトルとして使用できます。これにより、コレクション内の近傍データを素早く検証することが可能になります。

- Demo dataset

    Zilliz Cloud は、初心者がベクトルデータベースの機能に慣れ親しむためのデモデータセットを提供するようになりました。このデモデータセットは Kaggle データセットをもとに作成されており、2020年1月から2020年8月の間に著名な出版物で公開された5,000件以上の記事の詳細情報を含んでいます。

    これにより、データ準備の手間をかけることなく、ベクトルデータベースの全機能を簡単に体験できます。[ぜひお試しください！](https://cloud.zilliz.com/signup)
