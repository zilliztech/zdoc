        ## Milvus v2.6.x パブリックプレビュー\{#milvus-v26x-public-preview}

        今回のリリースにより、**Milvus v2.6.x クラスター**が Zilliz Cloud 上で**パブリックプレビュー**として利用可能になり、安定性・効率性・柔軟性を向上させる複数の機能強化と最適化が含まれています。

        - **ダウンタイムなしのフィールド追加** — スキーマの回避策なしに、コレクションに新しいフィールドをオンザフライで追加できます。詳細については、[既存のコレクションへのフィールド追加](./add-fields-to-an-existing-collection)をご参照ください。

        - **強化された全文検索** — Elasticsearch より最大 **4倍高速**で、多言語対応およびフレーズ一致機能を提供します。詳細については、[多言語アナライザー](./multi-language-analyzers)、[フレーズ一致](./phrase-match)、および[ユースケースに合ったアナライザーの選択](./choose-the-right-analyzer-for-your-use-case)をご参照ください。

        - **高速化されたJSONフィルタリング** — **JSONインデックス**および**シャレディング**により、複雑なネストされたメタデータクエリを最大 **100倍高速**に実行できます。詳細については、[JSONインデックス](./json-indexing)および[JSONシャレディング](./json-shredding)をご参照ください。

        - **新しい再ランキング関数** — **Boost Ranker** および **Decay Ranker** は、意味的類似性と文脈的関連性を組み合わせて検索結果を洗練します。詳細については、[Boost Ranker](./boost-ranker)および[Decay Ranker](./decay-ranker)をご参照ください。

        - **INT8ベクトルサポート** — 量子化されたベクトルを保存し、軽量なディープラーニング推論を実現します。詳細については、[Dense Vector](./use-dense-vector)をご参照ください。

        - **MINHASH_LSHインデックス** — MinHash および Locality-Sensitive ハッシュ化（局所性鋭敏ハッシュ化）を活用して、大規模な重複排除および類似性チェックを効率的に実行します。この機能は**プライベートプレビュー**として提供されており、ご興味がある場合は[お問い合わせください](https://support.zilliz.com/hc/en-us)。詳細については、[MINHASH_LSH](./minhash-lsh)をご参照ください。

        - **部分的なアップサート** — レコード全体を書き換えずに特定のフィールドのみを更新できます。詳細については、[エンティティのアップサート](./upsert-entities#upsert-in-merge-mode)をご参照ください。

        **パブリックプレビュー**を有効にするには、Zilliz Cloud コンソールの **クラスター概要** ページで **プレビュー機能を試す** を選択し、クラスターを Milvus v2.6.x にアップグレードしてください。アップグレード後も、Milvus v2.5.x の機能は引き続き利用可能です。

        ## 階層型ストレージのアップグレード\{#tiered-storage-upgrade}

        Zilliz Cloud の階層型ストレージがアップグレードされ、パフォーマンスとコスト効率が最適化されました。すべての拡張容量クラスターは新しいアーキテクチャに移行され、以下の主要な改善が提供されます。

        - **スマートデータ管理**: アクセスパターンに基づき、データを自動的に Hot（メモリ）、Warm（SSD）、Cold（オブジェクトストレージ）の各階層間で移動し、パフォーマンスとコスト効率を向上させます。

        - **キャッシュヒット率の向上**: キャッシュヒット率が90%以上となり、ほとんどのクエリが高速な階層から処理されます。

        - **コスト削減**: コンピュートコストが25%削減され、ストレージコストは1GBあたり月額30セントから4セントへと87%削減されます。10TBのデータセットの場合、月間ストレージコストは3,000ドルから400ドルに低下し、高いパフォーマンスを維持します。

        ## クロスリージョンバックアップ\{#cross-region-backup}

        Zilliz Cloud では、専用クラスター向けにクロスリージョンバックアップがサポートされるようになり、ディザスタリカバリ機能が強化されました。この機能により、クラウドリージョン全体の障害にも耐えられるよう、バックアップが自動的に他のリージョンにレプリケートされます。

        **主要機能**

        - **自動レプリケーション**: バックアップポリシーを一度設定すれば、Zilliz Cloud が継続的に選択した宛先リージョンへのレプリケーションを自動で処理します。

        - **地理的冗長性**: バックアップコピーを元のバックアップとは物理的に離れた場所に保存することで、リージョン単位の障害から保護します。

        - **迅速な復旧**: クロスリージョンバックアップから新しいクラスターへ迅速にデータを復元でき、ダウンタイムを最小限に抑え、リカバリータイムオブジェクティブ（RTO）を大幅に改善します。

        詳細については、[他のリージョンへのコピー](./backup-to-other-regions)をご参照ください。

        ## インデックスビルドレベル\{#index-build-level}

        Milvus 2.6.x および次世代量子化エンジンにより、検索精度（リコール）とデータ容量のトレードオフをアプリケーションのニーズに合わせて微調整できます。Zilliz Cloud の新しい「インデックスビルドレベル」機能により、ベクトル検索のパフォーマンスを制御でき、インデックス作成時に以下の3つのレベルから選択できます。

        - **精度優先**: 精度が極めて重要なミッションクリティカルなアプリケーション向けに、検索精度を最大化します。

        - **バランス（デフォルト）**: ほとんどのユースケースに推奨される設定で、リコール、パフォーマンス、容量の理想的なバランスを提供します。

        - **容量優先**: データ密度を最適化し、クエリのリコールを犠牲にすることで、予算内でより多くのベクトルを保存できます。

        詳細については、[インデックスビルドレベルの調整](./tune-index-build-level)をご参照ください。

        ## 機能強化\{#enhancements}

        - **アナライザGUI** を使用して、**言語固有のテンプレート**に基づきアナライザを素早く設定し、その結果を**テスト**できるようになりました。これにより、ユーザーはアナライザ設定がトークン化にどのように影響し、最終的に全文検索結果にどのような影響を与えるかを理解しやすくなります。デモについては、[アナライザ概要](./analyzer-overview#example-use-on-the-zilliz-cloud-console)をご参照ください。

        - より明確なエラーメッセージと強化されたユーザーエクスペリエンスにより、ユーザーは**接続の問題を診断する**ことや、マイグレーション用のソースデータベースをより簡単に設定できるようになりました。

        - データなしでコレクションをクローンする際に、スキーマを編集してコレクション設定を変更できるようになりました。

        ## 非推奨のお知らせ\{#deprecation-notice}

        - パイプライン機能は非推奨となり、現在はオフラインになっています。
