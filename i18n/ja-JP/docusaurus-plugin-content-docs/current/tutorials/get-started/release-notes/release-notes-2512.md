# 2025 年 12 月リリースノート

<Grid columnSize="2" widthRatios="16,83">

    <div>

        **2025-12-26**

    </div>

    <div>

        ## Milvus v2.6 GA\{#milvus-v26-ga}

        このリリースは、Milvus v2.6.x の GA マイルストーンを記念するものであり、Zilliz Cloud 上で本番環境対応の安定性と完全な機能サポートをもたらします。これには、ジオメトリ、構造体、および TimestampTz データ型、ダウンタイムなしでのフィールド追加、強化された全文検索、高速化された JSON フィルタリング、新しい再ランキング関数、INT8 ベクトルサポート、部分的なアップサート、および MINHASH_LSH インデックスが含まれます。

        ティアードストレージも GA に到達し、アップグレードされたホット/ウォーム/コールドアーキテクチャを導入し、コールドデータアクセスの課金を開始します。詳細については、[ストレージコスト](./storage-cost#cold-data-access) をご覧ください。

    </div>

</Grid>

        ## 機能強化\{#enhancements}

        - Milvus エンドポイントの移行が ジオメトリ および 構造体 データ型をサポートするようになり、空間形状や深くネストされた属性を持つコレクションのシームレスな移行が可能になりました。

        - 課金コンソールで Advance 残高が表示されるようになり、前払い利用状況と残高の可視性が向上しました。

        - RESTful API が自動スケーリング設定をサポートするようになり、クラスターのエラスティシティポリシーをプログラム的に管理できるようになりました。

        - ジョブセンターがより詳細な進捗状況の更新を提供し、ユーザーがジョブのステータスと実行ステージをより明確に把握できるようになりました。

        - 登録フローが簡素化されたフォームにより最適化され、オンボーディングの効率と全体的なユーザーエクスペリエンスが向上しました。

        ## ボリューム GA（旧 ステージ）\{#volume-ga-formerly-stage}

        **ステージが GA に到達しました**ことを発表でき、正式に**ボリューム**に改名されたことを嬉しく思います。ボリュームは、構造化テーブルまたは非構造化データファイルのコレクションを格納するマネージドオブジェクトストアであり、Zilliz Cloud におけるスケーラブルなデータ取り込みと ETL ワークフローのための統一データレイヤーとして機能します。

        この GA リリースの新機能：

        - **ボリュームレベル RBAC** 

            読み書き権限に対するきめ細かいロールベースのアクセス制御。

        - **コンソールサポート**

            Zilliz Cloud コンソールで直接ボリュームを作成、管理、監視できます。

        - **GCP サポート** 

            ボリュームは現在**AWS と GCP**をサポートしており、マルチクラウドの柔軟性を実現します。

        - GA により、ボリュームはフリートライアルボリュームと従量課金ボリュームの 2 つの課金モードをサポートします。従量課金ボリュームはストレージ使用量に基づいて課金が開始されます。

        - 詳細については、「ボリューム の解説」、「ボリュームの管理（SDK）」、および「ボリュームの管理（コンソール）」を参照してください。

        ## 組織レベル IP アクセス許可リスト\{#organization-level-ip-access-allowlist}

        セキュリティを強化し、企業のコンプライアンス要件を満たすために、Zilliz Cloud はエンタープライズプランおよびビジネスクリティカルプラン向けに組織レベルの IP アクセス許可リストをサポートします。

        - **きめ細かなアクセス制御** 

            組織オーナーは、コンソールアクセスのために信頼できる IPv4 アドレスまたは CIDR 範囲を定義できます。承認されていないソースからのトラフィックはブロックされます。

        - **包括的な監査**

            すべての許可リストのライフサイクルイベント（有効化、無効化、ルール変更）がプラットフォーム監査ログに記録されます。

        - 詳細については、[コンソール IP 許可リストの設定](./setup-console-ip-allowlist) を参照してください。

        ## MFA セキュリティアップグレード:\{#mfa-security-upgrade}

        Zilliz Cloud は現在、**TOTP ベースの MFA**（例：Google/Microsoft Authenticator）をサポートしており、E メールベースの認証よりも強力な保護を提供します。

        - **組織レベルでの適用**: エンタープライズプランの管理者は、コンプライアンス基準を確保するために、すべての組織メンバーに対して必須の MFA ポリシーを適用できるようになりました。

        - **レガシー移行**: E メールのみによる MFA は廃止されます。既存のユーザーには、認証アプリへの移行を促すプロンプトが表示されます。

        - 詳細については、[MFA](./multi-factor-auth) を参照してください。
