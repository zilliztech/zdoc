# リリースノート（2023年9月27日）

Zilliz Cloud のローンチを発表できることを嬉しく思います。このリリースでは、新しい CU サイズオプションによる 柔軟性 の向上、前払いのサポート、さらに多くの AWS リージョンなど、さまざまな機能強化と新機能を導入しています。

## Milvus 互換性\{#milvus-compatibility}

このリリースは **Milvus 2.2.x** と互換性があります。

## クラスター機能強化 - 新しい CU サイズオプションによる 柔軟性 の向上\{#cluster-enhancements-increased-flexibility-with-a-new-cu-size-option}

新しいクラスターサイズオプションである 6 CU が追加され、クラスター管理がさらに柔軟になりました。このオプションは、よりコスト効果が高く効率的なクラスターオプションを求める、小規模なデータセットをお持ちのユーザーに最適です。特定のニーズに合わせたパフォーマンスの向上を体験できます。

## 前払いのサポート\{#support-for-advance-pay}

前払いのサポートを開始しました。この機能は、消費するサービスを事前に支払うことを希望されるオフライン契約ユーザーのために特別に設計されています。このオプションを提供することで、社内の財務・調達プロセスを効率化し、大切なお客様のリスクを最小化することを目指しています。

特定の要件がある場合や、前払いオプションについて詳しく知りたい場合は、お気軽に [お問い合わせ](https://zilliz.com/contact-sales) ください。

## さらに多くの AWS リージョン\{#more-aws-regions}

新しい AWS リージョン、US East 1（aws-us-east-1）のサポートを開始したことを発表いたします。このリージョンの追加により、ユーザーはこのリージョンでのデータ処理能力を強化するために当社のサービスを活用できます。

## その他のハイライト\{#other-highlights}

- クレジット有効期限監視機能の UI 強化

- Playground 機能のユーザーエクスペリエンス改善
