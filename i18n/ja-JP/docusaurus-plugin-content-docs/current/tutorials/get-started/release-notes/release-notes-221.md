# リリースノート（2023年9月27日）

Zilliz Cloud のローンチを発表できることを大変うれしく思います。このリリースでは、新しい CU サイズオプションによる柔軟性の向上、前払いのサポート、さらに多くの AWS リージョンなど、さまざまな改善と機能を導入しています。

## Milvus 互換性\{#milvus-compatibility}

このリリースは **Milvus 2.2.x** と互換性があります。

## クラスターの機能強化 - 新しい CU サイズオプションによる柔軟性の向上\{#cluster-enhancements-increased-flexibility-with-a-new-cu-size-option}

新しいクラスターサイズオプションである 6 CU の追加により、クラスター管理がより柔軟になりました。このオプションは、よりコスト効率が高く効率的なクラスターオプションを求める、小規模なデータセットを扱うユーザーに最適です。お客様固有のニーズに合わせて調整された、向上したパフォーマンスをご体験ください。

## 前払いのサポート\{#support-for-advance-pay}

このたび、前払いのサポートを提供開始しました。この機能は、利用するサービスに対して事前に支払いたいオフライン契約ユーザー向けに特別に設計されています。このオプションを提供することで、社内の財務および調達プロセスを効率化し、大切なお客様のリスクを最小限に抑えることを目指しています。

お客様またはお客様の組織に特別な要件がある場合、あるいは前払いオプションの詳細を知りたい場合は、どうぞお気軽に[お問い合わせください](https://zilliz.com/contact-sales)。

## その他の AWS リージョン\{#more-aws-regions}

新しい AWS リージョンとして US East 1 (aws-us-east-1) をサポートするようになりました。このリージョンの追加により、ユーザーはこのリージョンでのデータ処理能力を強化するために当社のサービスを活用できるようになります。

## その他のハイライト\{#other-highlights}

- クレジット有効期限監視機能の UI を強化

- Playground 機能のユーザー体験を改善
