# リリースノート（2023年9月27日）

Zilliz Cloud のローンチを発表できることを大変嬉しく思います。今回のリリースでは、新しい CU サイズオプションによる柔軟性の向上、前払い（advance pay）のサポート、さらなる AWS リージョンの追加など、さまざまな機能強化と新機能を導入しています。

## Milvus 互換性\{#milvus-compatibility}

このリリースは **Milvus 2.2.x** と互換性があります。

## クラスター機能強化 - 新しい CU サイズオプションによる柔軟性の向上\{#cluster-enhancements-increased-flexibility-with-a-new-cu-size-option}

新しいクラスターサイズオプション「6 CU」が追加され、クラスター管理がより柔軟になりました。このオプションは、小規模なデータセットを扱うユーザーにとって、コスト効率が高く効率的なクラスターオプションです。お客様の具体的なニーズに合わせたパフォーマンスの向上を体験できます。

## 前払い（Advance Pay）のサポート\{#support-for-advance-pay}

前払い（advance payment）のサポートを開始しました。この機能は、利用するサービスに対して事前に支払いを行うことを希望される、オフライン契約のお客様向けに特別に設計されています。このオプションを提供することで、お客様の社内の財務および調達プロセスを合理化し、リスクを最小限に抑えることを目指しています。

貴社または組織で特定の要件がある場合や、前払いオプションについてさらに詳しく知りたい場合は、お気軽に [お問い合わせください](https://zilliz.com/contact-sales)。

## さらなる AWS リージョンの追加\{#more-aws-regions}

新たに AWS リージョン「US East 1 (aws-us-east-1)」をサポート開始しました。このリージョンの追加により、ユーザーはこの地域においてデータ処理能力を強化するための当社サービスを活用できるようになります。
