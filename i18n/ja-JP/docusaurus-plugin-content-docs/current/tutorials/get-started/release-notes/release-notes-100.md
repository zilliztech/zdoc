# リリースノート（2023年3月6日）

Zilliz Cloud の大規模なアップデートの一般提供開始をお知らせします。このリリースでは、使いやすさ、セキュリティ、パフォーマンス、機能性におけるベクトルデータベースサービスの標準を新たな段階へと引き上げ、あらゆる人のために構築された最先端のベクトルデータベース体験をお届けします。

- 10億規模のベクトルコレクションのサポート

    このリリースにより、Zilliz Cloud はベクトルデータベースの容量上限を10億規模まで引き上げました。これにより、エンタープライズユーザーは Zilliz Cloud の Web インターフェースから [32 CU のデータベースインスタンス](https://zilliz.com/pricing)（performance-optimized CU と capacity-optimized CU の両方）を作成できるようになりました。

    PoC または本番環境へのデプロイ向けにさらに大きなインスタンスが必要なユーザーは、ぜひ [お問い合わせください](https://zilliz.com/contact-sales)。最大 256 performance-optimized CUs（128 次元ベクトルを 13 億件処理可能）または 128 capacity-optimized CUs（128 次元ベクトルを 30 億件処理可能）のインスタンスをご利用いただけます。

- パフォーマンスの向上

    この更新版の Zilliz Cloud は Milvus 2.2.3 をベースに構築されています。Milvus 2.2.3 により、元の Milvus 2.0.0 リリースと比較して検索レイテンシを 2.5 倍削減しました。より低いレイテンシはすべてのユーザーにメリットがありますが、特にレコメンデーションシステム、画像/動画/テキスト検索、質問応答などのリアルタイム情報検索システムでは重要です。

    同一環境でのテストでは、Milvus 2.2.3 は 2.0.0 と比べて QPS が 4.5 倍向上したことが示されました。この向上により、Milvus はハードウェア効率およびコスト効率がさらに高まり、大規模なベクトル検索プラットフォームの構築において極めて重要となっています。

    詳細については、[ホワイトペーパー](https://zilliz.com/resources/milvus-performance-benchmark)をご覧ください。

- GCP 上の Zilliz Cloud

    Zilliz Cloud が Google Cloud Platform（GCP）で利用可能になったことをお知らせします。Zilliz Cloud は最高の体験を提供し、スタートアップから大企業まで、さまざまなユーザーの多様な要件に対応します。GCP 上にマネージドベクトルデータベースインスタンスを数クリックでデプロイできます。

    us-west1 リージョン（オレゴン州ダレス）が利用可能になりました。GCP 上の当社サービスの CU あたりの料金は、performance-optimized と capacity-optimized の両タイプとも 1 時間あたり &#36;0.215 で、ストレージ料金は 1 か月あたり &#36;0.02/GB です。

- AWS Marketplace

    Zilliz Cloud は [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-iqbidum7feuio) でも利用可能で、AWS 上で当社のフルマネージドベクトルデータベースサービスにこれまで以上に簡単にアクセスできます。AI アプリケーションへの需要が高まる中、この統合はまさに絶好のタイミングで実現しました。AWS Marketplace 上の Zilliz Cloud により、ユーザーは AI アプリケーションを迅速に構築し、スケールできます。

    この統合の利点の 1 つは、製品をシームレスに管理できることです。請求、キャンセル、返金などをすべてユーザーの AWS アカウント上で管理および追跡できます。この機能だけでも時間と手間を節約でき、プロセス全体を簡素化します。

    もう 1 つの利点は、AWS Cost Explorer を通じてコストを確認できることです。このツールを使うことで、支出を簡単に追跡し、請求およびコスト管理プロセスへの理解を深めることができます。

    詳細については、[AWS Marketplace でサブスクライブ](./subscribe-on-aws-marketplace) を参照してください。

- ローリングアップグレード

    Milvus ユーザーは、システムの健全性を維持するために定期的にさまざまなメンテナンス作業を実施する必要がありました。しかし、本番システムでのメンテナンス作業にはリスクが伴います。通常、メンテナンス作業は予定されたダウンタイム中に実施されるため、データベースをオフラインにし、通常の業務運用を停止する必要があります。残念ながら、今日のユーザーは長時間のダウンタイムを許容しません。

    良いニュースとして、Zilliz Cloud はローリングアップグレードをサポートするようになりました。ベクトルデータベースを Zilliz Cloud 上にデプロイしていれば、予定メンテナンスを心配する必要はもうありません。代わりに、メンテナンスウィンドウを設定してビジネスに集中してください。残りは私たちが対応します。ほとんどの場合、ローリングアップグレードによるサービス停止時間は月あたり 1 分未満です。

- バックアップと復元

    バックアップと復元機能が Zilliz Cloud で利用可能になりました。データ損失は、いつでも誰にでも起こり得ます。ハードウェア障害、ソフトウェアの不具合、あるいは人的ミスであっても、その結果は深刻になり得ます。そのため、データベースに対して信頼性の高いバックアップおよび復旧ソリューションを導入しておくことが重要です。

    新しいバックアップと復元機能により、データベースを簡単にバックアップし、予期しない損失が発生した場合に復元できるようになりました。

    詳細については、[Create Backup](./create-backup) とその関連ページを参照してください。

- Recycle Bin

    データセキュリティは常に私たちの最優先事項です。このリリースでは、Zilliz Cloud に Recycle Bin を導入し、データの安全性をさらに高めました。たとえば、ユーザーがデータベースを削除した場合や、無料トライアル中の長期間の非アクティブ状態、または未払い料金によるサービス停止によって自動削除された場合、Zilliz Cloud は自動的にデータベース/コレクションを Recycle Bin に移動し、その後 30 日間はいつでもデータを復元できます。

    詳細については、[Use Recycle Bin](./use-recycle-bin) を参照してください。

- オープンソース Milvus からのデータベース移行

    このリリースでは、データベース移行ツールキットを導入します。これにより、オープンソース Milvus ユーザーはローカルデータベースを Zilliz Cloud に簡単に移行でき、システムメンテナンスの負担から解放されます。さらに、移行ツールは Milvus 1.x および 2.x と互換性があります。そのため、Milvus のバージョンに関係なく、わずか 2 ステップでデータベースを簡単に Zilliz Cloud に移行できます。

    詳細については、[Milvus から Zilliz Cloud への移行](./migrate-from-milvus) を参照してください。

- その他の優れたアップデート

    新しい請求書ページでは、さまざまなリソース使用量とサービスの詳細コスト、クレジットの使用状況、適用可能な割引ルールが表示されるようになりました。データプレビューの体験も改善されています。さらに、安定性とメモリ使用効率を向上させるためのいくつかのバグ修正も行われました。
