# リリースノート（2023年3月6日）

Zilliz Cloud の大幅なアップデートの一般提供を発表できることを嬉しく思います。このリリースでは、ベクトルデータベースサービスの利便性、セキュリティ、パフォーマンス、および機能の標準を新たな段階に引き上げ、あらゆるユーザー向けに構築された最先端のベクトルデータベース体験を提供します。

- 10億規模のベクトルコレクションサポート

    このリリースにより、Zilliz Cloud はベクトルデータベースの容量制限を10億規模まで拡張しました。これにより、エンタープライズユーザーは Zilliz Cloud の Web インターフェースから [32 CU のデータベースインスタンス](https://zilliz.com/pricing)（パフォーマンス最適化 CU および容量最適化 CU の両方）を作成できるようになりました。

    PoC または本番デプロイメントのためにより大きなインスタンスが必要なユーザーは、遠慮なく [お問い合わせ](https://zilliz.com/contact-sales) ください。最大256のパフォーマンス最適化 CU（13億の128次元ベクトルを処理可能）または128の容量最適化 CU（30億の128次元ベクトルを処理可能）のインスタンスを取得できます。

- パフォーマンスの向上

    この更新版の Zilliz Cloud は Milvus 2.2.3 をベースに構築されています。Milvus 2.2.3 により、オリジナルの Milvus 2.0.0 リリースと比較して検索レイテンシを2.5倍削減しました。低レイテンシはすべてのユーザーにメリットをもたらしますが、レコメンデーションシステム、画像/動画/テキスト検索、質問応答などのリアルタイム情報検索システムを扱う際に特に重要です。

    同一環境下でのテストでは、Milvus 2.2.3 で 2.0.0 と比較して QPS が4.5倍増加しました。この増加により、Milvus はさらにハードウェアとコスト効率に優れたものとなり、大規模ベクトル検索プラットフォームの構築において重要です。

    詳細については、[ホワイトペーパー](https://zilliz.com/resources/milvus-performance-benchmark) をご覧ください。

- GCP 上の Zilliz Cloud

    Zilliz Cloud が Google Cloud Platform（GCP）で利用可能になったことを発表します。Zilliz Cloud は、スタートアップから大企業まで、さまざまなユーザーの多様な要件に応える最適な体験を提供します。GCP 上でマネージドベクトルデータベースインスタンスを数回のクリックでデプロイできます。

    us-west1 リージョン（オレゴン州ザ・ダレス）が現在利用可能です。GCP 上でのサービスの CU あたりのコストは、パフォーマンス最適化タイプおよび容量最適化タイプの両方で1時間あたり &#36;0.215 で、ストレージコストは1GBあたり月額 &#36;0.02 です。

- AWS Marketplace

    Zilliz Cloud は [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-iqbidum7feuio) でも利用可能であり、AWS 上で完全にマネージドされたベクトルデータベースサービスにアクセスするのがこれまで以上に簡単になりました。この統合は、AI アプリケーションへの需要が高まる中、絶好のタイミングで実現しました。AWS Marketplace 上の Zilliz Cloud を使用すると、ユーザーは AI アプリケーションを迅速に構築およびスケールできます。

    この統合の利点の1つは、製品をシームレスに管理できることです。請求、キャンセル、返金などはすべて、ユーザーの AWSアカウント で管理および追跡できます。この機能だけで、時間と手間を節約し、プロセス全体を効率化できます。

    もう1つの利点は、AWS Cost Explorer を通じてコストを確認できることです。このツールを使用すると、費用を簡単に追跡し、請求およびコスト管理プロセスについての洞察を得ることができます。

    詳細については、[AWS Marketplace での購読](./subscribe-on-aws-marketplace) を参照してください。

- ローリングアップグレード

    Milvus ユーザーは、システムの健全性を確保するために定期的にさまざまなメンテナンスタスクを実行する必要がありました。しかし、本番システムでのメンテナンス作業はリスクを伴います。通常、メンテナンス作業はスケジュールされたダウンタイム中に実行され、データベースをオフラインにして通常の業務運用を停止する必要があります。残念ながら、現在のユーザーは長期間のダウンタイムを許容しません。

    良いニュースは、Zilliz Cloud がローリングアップグレードをサポートしたことです。ベクトルデータベースを Zilliz Cloud にデプロイすれば、スケジュールされたメンテナンスを心配する必要はありません。代わりに、メンテナンスウィンドウを設定し、ビジネスに集中してください。残りは私たちが処理します。ほとんどの場合、ローリングアップグレードによるサービスダウンタイムは月あたり1分未満です。

- バックアップと復元

    バックアップと復元機能が Zilliz Cloud で利用可能になりました。データの損失は、誰にでもいつでも起こり得ます。ハードウェア障害、ソフトウェアの不具合、あるいは人為的なミスによるものであっても、その結果は壊滅的になる可能性があります。これが、データベースに対して信頼性の高いバックアップおよび復旧ソリューションを用意することが重要な理由です。

    新しいバックアップおよび復元機能により、データベースを簡単にバックアップし、予期しない損失が発生した場合に復元できるようになりました。

    詳細については、[バックアップと復元](./backup-and-restore) を参照してください。

- ごみ箱

    データセキュリティは常に私たちの最優先事項です。このリリースでは、Zilliz Cloud にごみ箱を導入し、データをさらに安全に保護します。たとえば、ユーザーがデータベースを削除した場合、または無料トライアルの長期間の非アクティビティや未払い料金によるサービス停止により自動的に削除された場合、Zilliz Cloud は自動的にデータベース/コレクションをごみ箱に移動し、今後30日間はいつでもデータを復元できます。

    詳細については、[ごみ箱の使用](./use-recycle-bin) を参照してください。

- オープンソース Milvus からのデータベース移行

    このリリースでは、データベース移行ツールキットを導入します。これにより、オープンソース Milvus ユーザーはローカルのデータベースを Zilliz Cloud に簡単に移行でき、システムメンテナンスの負担から解放されます。さらに、移行ツールは Milvus 1.x および 2.x と互換性があります。したがって、Milvus のバージョンに関わらず、わずか2ステップでデータベースを Zilliz Cloud に簡単に移行できます。

    詳細については、[移行](./migrations) を参照してください。

- その他の素晴らしいアップデート

    新しい請求書ページでは、さまざまなリソース使用状況とサービスの詳細なコスト、クレジットの使用方法、および適用される割引ルールが表示されるようになりました。データプレビューの体験が改善されました。安定性とメモリ使用率を向上させるいくつかのバグ修正を行いました。
