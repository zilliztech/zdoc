# リリースノート（2023年3月6日）

Zilliz Cloud の重要なアップデートの一般提供開始をお知らせします。このリリースにより、ベクトルデータベースサービスの使いやすさ、セキュリティ、パフォーマンス、機能性の基準が新たな段階へと引き上げられ、あらゆる人のために構築された最先端のベクトルデータベース体験をお届けします。

- 10億規模の Vector Collection サポート

    このリリースにより、Zilliz Cloud はベクトルデータベースの容量上限を10億規模へと引き上げました。これにより、エンタープライズユーザーは Zilliz Cloud の Web インターフェースから [32 CU のデータベースインスタンス](https://zilliz.com/pricing)（performance-optimized CU と capacity-optimized CU の両方）を作成できるようになりました。

    PoC または本番デプロイ向けにより大きなインスタンスが必要なユーザーは、ぜひ [お問い合わせ](https://zilliz.com/contact-sales) ください。最大 256 performance-optimized CUs（13億件の128次元 vector に対応）または 128 capacity-optimized CUs（30億件の128次元 vector に対応）のインスタンスをご利用いただけます。

- パフォーマンスの向上

    この更新版の Zilliz Cloud は Milvus 2.2.3 をベースに構築されています。Milvus 2.2.3 では、初期の Milvus 2.0.0 リリースと比較して検索レイテンシを 2.5 倍削減しました。レイテンシの低下はすべてのユーザーにメリットがありますが、特にレコメンデーションシステム、画像/動画/テキスト検索、質問応答などのリアルタイム情報検索システムでは重要です。

    同一環境下でのテストでは、Milvus 2.2.3 は 2.0.0 と比較して QPS が 4.5 倍向上したことが確認されました。この向上により、Milvus はさらにハードウェア効率およびコスト効率に優れ、大規模なベクトル検索プラットフォームの構築において重要な利点となります。

    詳細については、[ホワイトペーパー](https://zilliz.com/resources/milvus-performance-benchmark) をご覧ください。

- GCP 上の Zilliz Cloud

    Zilliz Cloud が Google Cloud Platform (GCP) で利用可能になったことをお知らせします。Zilliz Cloud は最高の体験を提供し、スタートアップから大企業まで、さまざまなユーザーの多様な要件に対応します。数回のクリックだけで、GCP 上にマネージドベクトルデータベースインスタンスをデプロイできます。

    現在、us-west1 リージョン（オレゴン州 The Dalles）が利用可能です。GCP 上の当社サービスの CU あたりのコストは、performance-optimized と capacity-optimized の両タイプとも 1 時間あたり &#36;0.215、ストレージコストは 1 か月あたり &#36;0.02/GB です。

- AWS Marketplace

    Zilliz Cloud は [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-iqbidum7feuio) でも利用可能になり、AWS 上で当社のフルマネージドベクトルデータベースサービスにこれまで以上に簡単にアクセスできるようになりました。AI アプリケーションへの需要が高まる今、この統合はまさに絶好のタイミングです。AWS Marketplace 上の Zilliz Cloud により、ユーザーは AI アプリケーションを迅速に構築し、スケールできます。

    この統合の利点の 1 つは、製品をシームレスに管理できることです。請求、キャンセル、返金などをすべてユーザーの AWS アカウント上で管理および追跡できます。この機能だけでも、時間と手間を節約し、プロセス全体を効率化できます。

    もう 1 つの利点は、AWS Cost Explorer を通じてコストを確認できることです。このツールを使用すると、支出を簡単に追跡し、請求およびコスト管理プロセスに関する洞察を得ることができます。

    詳細については、[AWS Marketplace でサブスクライブする](./subscribe-on-aws-marketplace) を参照してください。

- ローリングアップグレード

    これまで Milvus ユーザーは、システムの健全性を維持するために定期的にさまざまなメンテナンスタスクを実行する必要がありました。しかし、本番システムでのメンテナンス作業にはリスクが伴います。通常、メンテナンスは計画停止時間中に実施されるため、データベースをオフラインにし、通常の業務運用を一時停止する必要があります。残念ながら、今日のユーザーは長時間のダウンタイムを許容しません。

    良い知らせとして、Zilliz Cloud はローリングアップグレードをサポートするようになりました。vector データベースを Zilliz Cloud にデプロイしていれば、計画メンテナンスを心配する必要はもうありません。代わりに、メンテナンスウィンドウを設定して、あとは当社に任せてビジネスに集中できます。ほとんどの場合、ローリングアップグレードによるサービスダウンタイムは月あたり 1 分未満です。

- Backup and Restore

    Backup and Restore 機能が Zilliz Cloud で利用可能になりました。データ損失は、誰にでも、いつでも起こり得ます。ハードウェア障害、ソフトウェアの不具合、あるいは人的ミスであっても、その結果は深刻なものになりかねません。そのため、信頼できるデータベースのバックアップおよびリカバリソリューションを用意しておくことが重要です。

    新しいバックアップおよびリストア機能により、データベースを簡単にバックアップし、予期しない損失が発生した場合に復元できるようになりました。

    詳細については、[Create Backup](./create-backup) および関連ページを参照してください。

- Recycler Bin

    データセキュリティは常に当社の最優先事項です。このリリースでは、Zilliz Cloud に Recycler Bin を導入し、お客様のデータをさらに安全にします。たとえば、ユーザーがデータベースを削除した場合や、無料トライアルでの長期間の非アクティブ状態、または未払い料金によるサービス停止によりデータベースが自動削除された場合、Zilliz Cloud は自動的にそのデータベース/collection を recycler bin に移動し、その後 30 日間はいつでもデータを復元できます。

    詳細については、[Recycle Bin を使用する](./use-recycle-bin) を参照してください。

- オープンソース Milvus からのデータベース移行

    このリリースでは、データベース移行ツールキットを導入します。これにより、オープンソース Milvus ユーザーはローカルデータベースを簡単に Zilliz Cloud に移行でき、システムメンテナンスの負担から解放されます。さらに、この移行ツールは Milvus 1.x および 2.x と互換性があります。そのため、わずか 2 ステップで、Milvus のバージョンに関係なく、データベースを簡単に Zilliz Cloud へ移行できます。

    詳細については、[Milvus から Zilliz Cloud へ移行する](./migrate-from-milvus) を参照してください。

- その他の優れたアップデート

    新しい請求書ページでは、さまざまなリソース使用量とサービスの詳細コスト、クレジットの使用状況、適用可能な割引ルールが表示されるようになりました。データプレビューの体験も改善されています。安定性とメモリ使用率を改善するためのいくつかのバグ修正も行いました。
