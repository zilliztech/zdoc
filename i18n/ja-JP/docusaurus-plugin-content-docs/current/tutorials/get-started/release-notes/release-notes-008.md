# リリースノート（2022年11月18日）

Zilliz Cloud のメジャーアップデートが一般公開され、招待なしでどなたでもご利用いただけるようになりました。今回のリリースでは、パフォーマンス向上のために最大32 CU（Compute Unit）を1つのデータベースに割り当て可能な、容量最適化型のCUを導入しました。また、ローカルファイルおよび AWS S3 バケットからのデータインポート機能、自動インデックス作成による操作簡略化、QPS およびクエリ遅延のリソースモニタリング機能も追加されました。さらに、データベース作成速度が5倍に高速化され、ユーザーインターフェイスも最適化されて、より優れたユーザーエクスペリエンスを提供します。

- 一般公開され、Zilliz Cloud への登録に招待が不要になりました。

- 容量最適化型 CU をサポートします。

- 1つのデータベースに最大32 CU を割り当てられるようになりました。

- ローカルファイルおよび AWS S3 バケットからのデータインポートをサポートします。

- [自動インデックス](./autoindex-explained)をサポートし、インデックスの種類を選択する必要がなくなりました。

- QPS およびクエリ遅延のための[リソースモニター](./metrics-and-alerts)の設定をサポートします。

- データベース作成のパフォーマンスが5倍向上しました。

- UI のパフォーマンスを最適化し、ユーザーエクスペリエンスを向上させました。
