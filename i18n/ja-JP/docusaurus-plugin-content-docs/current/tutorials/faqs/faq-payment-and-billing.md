## よくある質問




### 各 Marketplace 経由でサブスクライブしている場合、AWS、GCP、Azure の Credits を Zilliz Cloud の使用量に充当できますか？\{#can-i-use-aws-gcp-or-azure-credits-to-offset-zilliz-cloud-usage-when-subscribed-via-their-respective-marketplaces}

いいえ。AWS、GCP、Azure などのクラウドプロバイダーから提供される Credits を、各 Marketplace 経由でサブスクライブしている場合でも、Zilliz Cloud の使用量に充当することはできません。

Zilliz Cloud の使用量は、各クラウドプロバイダーの Marketplace を通じたサードパーティサービスとして請求されます。クラウドプロバイダーが発行する多くのプロモーション Credits やコミット済み利用 Credits は、自社のネイティブサービスにのみ適用され、サードパーティ Marketplace 購入には適用されません。

詳細については、各クラウドプロバイダーが提供する条件を参照してください。以下はそれらの条件からの抜粋です。

- [AWS Credits Terms](https://aws.amazon.com/awscredits/): AWS Credits は AWS アカウントに適用され、AWS サービスに対してのみ有効です。

- [Google Cloud Marketplace Terms](https://cloud.google.com/marketplace?hl=en): GCP Credits は通常、Google Cloud サービスにのみ適用されます。

- [Azure Credit Usage Guidance](https://learn.microsoft.com/en-us/azure/cost-management-billing/understand/understand-azure-marketplace-charges): Visual Studio などの Credits は通常、サードパーティ Marketplace オファーには適用されません。

### クレジットカードを追加した後、アカウントに残っている期限切れ Credits を引き続き使用できますか？\{#after-adding-a-credit-card-can-i-continue-to-use-the-expired-credits-left-in-my-account}

はい。アカウントに Credits が残っており、支払い方法を追加済みの場合、残りの Credits の有効期限は 1 年に延長されます。

### &#36;100 の Credits は期限切れになりますか？無料 Credits の有効期限を延長するにはどうすればよいですか？\{#will-my-and36100-credits-expire-how-can-i-extend-the-expiration-of-the-free-credits}

ビジネスメールで初めてアカウントを登録すると、30 日以内に使用できる &#36;100 の Credits を受け取ります。Credits の有効期限が近づいたら、支払い方法を追加することで有効期限を延長できます。その後、1 年以内に使用できる追加の &#36;100 Credits を受け取ります。

### Recycle Bin 内のデータは課金対象ですか？\{#is-data-in-the-recycle-bin-charged}

いいえ。Recycle Bin 内の削除済みデータには課金されません。
