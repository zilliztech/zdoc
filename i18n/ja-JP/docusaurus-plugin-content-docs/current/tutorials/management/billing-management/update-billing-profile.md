# 請求先プロファイルを更新

請求先プロファイルには、請求、請求書、税務記録に使用される組織情報および連絡先情報が含まれます。請求書が正しい会社名、住所、連絡先情報で発行されるよう、請求先プロファイルを最新の状態に保ってください。請求先プロファイルの詳細については、[請求書について理解する](./view-invoice#billing-profile)を参照してください。

<Admonition type="info" icon="📘" title="**注記**">

請求先プロファイルを管理するには、**Organization Owner** または **Organization Billing Admin** である必要があります。

</Admonition>

## 請求先プロファイルを更新\{#update-billing-profile}

![OyU3wocxShpyvAb18M6c7ymHnkF](https://zdoc-images.s3.us-west-2.amazonaws.com/OyU3wocxShpyvAb18M6c7ymHnkF.png)

<Procedures>

1. Zilliz Cloud コンソールで、**Billing** に移動します。

1. **Billing Profile** セクションの **Edit** をクリックします。

1. 必要な請求情報を更新します。**Confirm** をクリックします。

</Procedures>

## 請求先プロファイルを更新した後\{#after-you-update-the-billing-profile}

請求先プロファイルが更新されると、以後の請求書には新しい請求情報が使用されます。

すでに発行済みの請求書は変更されません。既存の請求書の情報を更新する必要がある場合は、finance@zilliz.com の Zilliz Finance チームまでお問い合わせください。
