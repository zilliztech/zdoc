# Cron 式を理解する

cron 式は、スケジュールされたスケーリングタスクがいつ実行されるかを定義します。Zilliz Cloud は、分単位の粒度を持つ標準的な 5 フィールドの Unix cron 形式を使用します。Cron スケジュールは、選択したタイムゾーンで評価されます。

```plaintext
* * * * *
│ │ │ │ └── 曜日
│ │ │ └──── 月
│ │ └────── 日
│ └──────── 時
└────────── 分
```

| フィールド | 有効な値の範囲 | 注記 |
| --- | --- | --- |
| `minute` | `0` から `59` | 1 時間の中の分。 |
| `hour` | `0` から `23` | 24 時間制を使用します。 |
| `day of month` | `1` から `31` | 月に指定した日が存在しない場合、その月にはスケジュールは実行されません。 |
| `month` | `1` から `12` | 年の中の月。 |
| `day of week` | `0` から `6` | `0` は日曜日、`1` は月曜日を表し、以降同様です。 |

### サポートされている演算子\{#supported-operators}

| 演算子 | 意味 | 例 |
| --- | --- | --- |
| `*` | 任意の値。 | `* * * * *` は毎分実行されます。 |
| `,` | 値のリスト。 | `0 9,17 * * *` は毎日 09:00 と 17:00 に実行されます。 |
| `-` | 値の範囲。 | `0 9-17 * * *` は 09:00 から 17:00 まで毎時実行されます。 |
| `/` | ステップ値。 | `*/5 * * * *` は 5 分ごとに実行されます。 |

### 一般的な cron テンプレート\{#common-cron-templates}

| ユースケース | Cron 式 | 意味 |
| --- | --- | --- |
| 毎日 09:30 | `30 9 * * *` | 毎日 09:30 に実行されます。 |
| 平日 09:00 | `0 9 * * 1-5` | 月曜日から金曜日の 09:00 に実行されます。 |
| 毎週日曜日 09:00 | `0 9 * * 0` | 毎週日曜日の 09:00 に実行されます。 |
| 1 日 2 回 | `0 9,21 * * *` | 毎日 09:00 と 21:00 に実行されます。 |
| 毎月 1 日の 09:00 | `0 9 1 * *` | 毎月 1 日の 09:00 に実行されます。 |

### スケジュールの例\{#example-schedules}

**平日のピーク時間帯にスケールアップし、業務後にスケールダウンする**

2 つのスケジュールを作成します。1 つはピーク時間前にスケールアップするため、もう 1 つはピーク時間後にスケールダウンするためです。

| スケジュール | Cron 式 | ターゲット |
| --- | --- | --- |
| 月曜日から金曜日の 09:00 にスケールアップ | `0 9 * * 1-5` | Query CU または replica をピーク時間帯のターゲットに設定します。 |
| 月曜日から金曜日の 19:00 にスケールダウン | `0 19 * * 1-5` | Query CU または replica をオフピークのターゲットに設定します。 |

**週末はリソースを少なくし、月曜日に復元する**

土曜日にスケールダウンするためのスケジュールを 1 つ作成し、月曜日に容量を復元するためのスケジュールを 1 つ作成します。

| スケジュール | Cron 式 | ターゲット |
| --- | --- | --- |
| 毎週土曜日の 00:00 にスケールダウン | `0 0 * * 6` | Query CU または replica を週末のターゲットに設定します。 |
| 毎週月曜日の 09:00 に復元 | `0 9 * * 1` | Query CU または replica を平日のターゲットに設定します。 |
