# データベースの説明

データベースは、プロジェクト内のコレクションの論理コンテナです。アプリケーション、テナント、環境ごとにデータを整理しやすくなり、コレクション名と操作を選択したデータベースのスコープ内に保つことができます。

Zilliz Cloud では、2つのデータベースモデルを使用します。

- **サービングクラスター内のデータベース**: Dedicated サービングクラスターでホストされるデータベースです。サービングクラスターエンドポイントを通じて、スキーマ管理、データの書き込み、削除、検索、クエリ、およびその他のコレクション操作をサポートします。

- **オンデマンド検索用データベース**: Zilliz Cloud によって管理されるプロジェクトレベルのデータベースです。サービングクラスターから独立しており、オンデマンドコンピュートを使用してプロジェクトエンドポイント経由でクエリされます。

<Admonition type="info" title="Note">

このページでは、データベースモデルについて説明します。データベースの作成と管理については、[サービングクラスター内のデータベース](./database) および [オンデマンド検索用データベース](./on-demand-database) を参照してください。

</Admonition>

## サービングクラスター内のデータベース\{#database-in-serving-clusters}

サービングクラスター内のデータベースは、特定の Dedicated サービングクラスター内に作成されます。Dedicated クラスターが作成されると、デフォルトのデータベースも同時に作成されます。必要に応じて、同じサービングクラスター内に追加のデータベースを作成できます。

サービングクラスター内のデータベースは、ホストするクラスターのライフサイクルに紐付けられます。

- サービングクラスターが一時停止されると、そのデータベースとコレクションは、クラスターが再開されるまで利用できなくなります。

- サービングクラスターが削除されると、そのデータベースとコレクションも同様に削除されます。

このモデルは、常時稼働で低レイテンシなデータアクセスを必要とする本番ワークロードに使用します。

```plaintext
Project
└── Serving Cluster
    ├── Database (default)
    │   ├── Collection_01
    │   └── Collection_02
    └── Database
        ├── Collection_03
        └── Collection_04
```

## オンデマンド検索用データベース\{#database-for-on-demand-search}

オンデマンド検索用データベースは、Zilliz Cloud によって管理されるプロジェクトレベルのデータベースです。サービングクラスターには紐付けられません。このデータベース内のデータを検索またはクエリする場合は、プロジェクトエンドポイントを使用し、オンデマンドコンピュートを指定します。

このモデルは、データベースとコレクションの管理、インポート、検索、クエリをサポートします。挿入、upsert、削除の操作はサポートしていません。

このモデルは、クエリ頻度が低い、またはバースト的なワークロードで search される大規模データセットに使用します。

```plaintext
Project
├── Serving Cluster
│   └── Database (default)
│       ├── Collection_01
│       └── Collection_02
└── Databases for on-demand search
    ├── Database
    │   └── External_Collection_01
    └── Database
        └── Managed_Collection_01
```

## 比較\{#comparison}

|  | **サービングクラスター内のデータベース** | **オンデマンド検索用データベース** |
| --- | --- | --- |
| 最適な用途 | 常時稼働で低レイテンシなデータアクセスを必要とする本番ワークロード | バースト的な検索やクエリを伴う大規模データセット |
| ホスト先 | サービングクラスター | プラットフォームが管理するプロジェクトリソース |
| エンドポイント | サービングクラスターエンドポイント | プロジェクトエンドポイント |
| コンピュートリソース | ホストするサービングクラスター | 指定したオンデマンドコンピュート |
| データベースの作成/drop | はい | はい |
| コレクションの作成/drop | はい | はい |
| コレクションのロード/release | はい | 不要 |
| 挿入/upsert/delete | はい | いいえ |
| インポート | はい | はい |
| 検索とクエリ | はい | はい |
| ライフサイクル | サービングクラスターに紐付けられます。 | サービングクラスターから独立しています。 |
