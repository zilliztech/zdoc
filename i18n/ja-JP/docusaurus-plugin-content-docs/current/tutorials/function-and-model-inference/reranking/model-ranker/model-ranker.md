# モデルベースのランカー

モデルベースのランカーは、クエリとドキュメント間の意味的関係を理解する高度な言語モデルを統合することで、Zilliz Cloud検索を変革します。ベクトル類似度にのみ依存するのではなく、コンテンツの意味や文脈を評価して、よりインテリジェントで関連性の高い検索結果を提供します。
