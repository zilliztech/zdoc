# Function & Model Inference

Zilliz Cloud の Function & Model Inference は、検索およびランキングワークフロー全体で、モデルベースのセマンティック理解や BM25 などのローカルメカニズムを、製品レベルの関数を通じて一貫性があり、かつ設定可能な方法で適用できる機能を提供します。
