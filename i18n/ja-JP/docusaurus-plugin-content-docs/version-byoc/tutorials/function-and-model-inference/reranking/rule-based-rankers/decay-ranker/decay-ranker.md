# Decay Ranker

この章では、Decay Ranker（減衰ランカー）について説明します。Decay Ranker は動的ランキング手法を用いて、特定の数値フィールドの値に応じて特定エンティティの類似度スコアを減衰させることで、他のエンティティを目立たせます。
