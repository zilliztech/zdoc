# 環境分離

適切な環境分離とアクセス制御は、エンタープライズアプリケーションの開発およびデプロイにおいて不可欠です。Zilliz Cloud は、**組織**、**プロジェクト**、および**クラスター**の階層構造を通じて柔軟な分離を提供します。このガイドでは、運用上、セキュリティ上、財務上の要件に基づいて、最も適切な戦略を選択するための支援を行います。

## プロジェクトレベルの分離\{#project-level-isolation}

このオプションは、請求の分離が要件ではない、ほとんどのエンタープライズグレードの本番環境デプロイに推奨されます。

**以下に最適:**

- 中程度の分離を伴うユーザー [ロール](./project-users#invite-a-user-to-a-project) の管理

**利点:**

- [プロジェクト](./projects) レベルできめ細かいユーザーアクセス制御

- 環境ごとの使用量追跡を伴う統合請求

- ほとんどのエンタープライズユースケースに十分な分離

## クラスターレベルの分離\{#cluster-level-isolation}

これは最も俊敏で軽量なオプションです。

**以下に最適:**

- 迅速な反復に注力する小チーム

- アクセス制御の必要性が最小限

- 基本的なワークロード分離

**機能:**

- 同じプロジェクト下での複数の [クラスター](./cluster)

- 各クラスターは、ワークロード分離のために専用のコンピューティング/ストレージリソースを持つ

- 運用と管理を容易にするための集中化された [モニタリング](./metrics-and-alerts)

## 適切な分離戦略の選択\{#choosing-the-right-isolation-strategy}

決定を導くために、以下のフローを使用してください:

1. **個別の請求書やインボイスが必要ですか?**
 → はい:**組織レベルの分離**を使用してください

1. **環境ごとにロールベースのアクセス制御が必要ですか?**
 → はい:**プロジェクトレベルの分離**を使用してください

1. **上記のいずれも該当しない場合?**
 → 簡素化のために**クラスターレベルの分離**を使用してください

個別の推奨事項については、[Zilliz Cloud サポートチーム](https://support.zilliz.com/hc/en-us) までお問い合わせください。
