# 請求プロファイルを更新する

請求プロファイルには、請求、請求書、税務記録に使用される組織および連絡先情報が含まれます。請求書が正しい会社名、住所、連絡先情報で発行されるように、請求プロファイルを最新の状態に保ってください。請求プロファイルの詳細については、[請求書を理解する](./view-invoice#billing-profile)を参照してください。

<Admonition type="info" icon="📘" title="**注記**">

請求プロファイルを管理するには、**Organization Owner** または **Organization Billing Admin** である必要があります。

</Admonition>

## 請求プロファイルを更新する\{#update-billing-profile}

![OyU3wocxShpyvAb18M6c7ymHnkF](https://zdoc-images.s3.us-west-2.amazonaws.com/OyU3wocxShpyvAb18M6c7ymHnkF.png)

<Procedures>

1. Zilliz Cloud コンソールで、**Billing** に移動します。

1. **Billing Profile** セクションで **Edit** をクリックします。

1. 必要な請求情報を更新します。**Confirm** をクリックします。

</Procedures>

## 請求プロファイルを更新した後\{#after-you-update-the-billing-profile}

請求プロファイルが更新されると、今後の請求書には新しい請求情報が使用されます。

すでに発行された請求書は変更されません。既存の請求書の情報を更新する必要がある場合は、finance@zilliz.com の Zilliz Finance チームに連絡してください。
