# Cron 式の理解

Cron 式は、スケジュールされたスケーリングタスクの実行タイミングを定義します。Zilliz Cloud は、分単位の粒度を持つ標準の 5 フィールド Unix cron 形式を使用します。Cron スケジュールは、選択したタイムゾーンに基づいて評価されます。

```plaintext
* * * * *
│ │ │ │ └── day of week
│ │ │ └──── month
│ │ └────── day of month
│ └──────── hour
└────────── minute
```

| フィールド | 有効な値の範囲 | 備考 |
| --- | --- | --- |
| `minute` | `0` 〜 `59` | 1 時間内の分を指定します。 |
| `hour` | `0` 〜 `23` | 24 時間制で指定します。 |
| `day of month` | `1` 〜 `31` | 指定された日がその月に存在しない場合、スケジュールは実行されません。 |
| `month` | `1` 〜 `12` | 年内の月を指定します。 |
| `day of week` | `0` 〜 `6` | `0` が日曜日、`1` が月曜日を意味し、以降も同様です。 |

### サポートされている演算子\{#supported-operators}

| 演算子 | 意味 | 例 |
| --- | --- | --- |
| `*` | 任意の値を表します。 | `* * * * *` は毎分実行されます。 |
| `,` | 値のリストを表します。 | `0 9,17 * * *` は毎日 09:00 と 17:00 に実行されます。 |
| `-` | 値の範囲を表します。 | `0 9-17 * * *` は 09:00 から 17:00 まで毎時実行されます。 |
| `/` | ステップ値を表します。 | `*/5 * * * *` は 5 分ごとに実行されます。 |

### 一般的な Cron テンプレート\{#common-cron-templates}

| ユースケース | Cron 式 | 意味 |
| --- | --- | --- |
| 毎日 09:30 | `30 9 * * *` | 毎日 09:30 に実行されます。 |
| 平日 09:00 | `0 9 * * 1-5` | 月曜日から金曜日の 09:00 に実行されます。 |
| 毎週日曜日 09:00 | `0 9 * * 0` | 毎週日曜日の 09:00 に実行されます。 |
| 1 日 2 回 | `0 9,21 * * *` | 毎日 09:00 と 21:00 に実行されます。 |
| 毎月 1 日 09:00 | `0 9 1 * *` | 毎月 1 日の 09:00 に実行されます。 |

### スケジュール例\{#example-schedules}

**平日のピーク時間帯にスケールアップし、業務終了後にスケールダウン**

ピーク時間帯の前にスケールアップするスケジュールと、ピーク時間帯の後にスケールダウンするスケジュールの 2 つを作成します。

| スケジュール | Cron 式 | ターゲット |
| --- | --- | --- |
| 月〜金の 09:00 にスケールアップ | `0 9 * * 1-5` | Query CU またはレプリカをピーク時間帯のターゲットに設定します。 |
| 月〜金の 19:00 にスケールダウン | `0 19 * * 1-5` | Query CU またはレプリカをオフピークのターゲットに設定します。 |

**週末はリソースを縮小し、月曜日に復元**

土曜日にスケールダウンするスケジュールと、月曜日にキャパシティを復元するスケジュールをそれぞれ作成します。

| スケジュール | Cron 式 | ターゲット |
| --- | --- | --- |
| 毎週土曜日の 00:00 にスケールダウン | `0 0 * * 6` | Query CU またはレプリカを週末のターゲットに設定します。 |
| 毎週月曜日の 09:00 に復元 | `0 9 * * 1` | Query CU またはレプリカを平日のターゲットに設定します。 |
