# オンデマンドコンピュート使用量を理解する

オンデマンドコンピュート使用量の詳細は、請求書に含まれるクエリコンピュートとインデックス構築コンピュートの使用量を理解するのに役立ちます。既存の請求書の使用量詳細を CSV ファイルとしてダウンロードし、請求書と並べて確認できます。

## オンデマンドコンピュート使用量\{#on-demand-compute-usage}

オンデマンドコンピュートには、2 種類のコンピュート使用量があります。

- **Query CU 使用量**は、オンデマンドクラスターがアクティブな間に消費するコンピュートリソースを測定します。

- **Indexing CU 使用量**は、マネージドコレクションと外部コレクションのインデックス構築ワークロードが消費するコンピュートリソースを測定します。

使用量の詳細は CU-分で表されます。料金は使用量と適用される単価によって異なります。コストの計算方法と請求規則については、[オンデマンドコンピュートコスト](/docs/on-demand-compute-cost) を参照してください。

## 使用量の詳細をダウンロードする\{#download-usage-details}

<Procedures>

1. Zilliz Cloud コンソールで、使用量を確認する請求書を開きます。

1. オンデマンドコンピュート使用量の詳細をダウンロードするオプションを選択します。

1. **Query CU** または **Indexing CU** を選択し、CSV ファイルをダウンロードします。

</Procedures>

ファイルには、選択した種類と請求書の使用量が含まれます。その種類の使用量がない場合、CSV には列ヘッダーのみが含まれます。

## Query CU 使用量を理解する\{#understand-query-cu-usage}

Query CU の CSV には、請求期間ごとに 1 行が含まれます。

| フィールド | 説明 |
| --- | --- |
| 請求書 ID と請求書明細項目 ID | 請求書と関連する明細項目を識別します。 |
| 請求期間の開始と終了 | UTC での請求期間の開始と終了です。開始は含み、終了は含みません。 |
| リージョン ID、プロジェクト ID、インスタンス ID | 使用量に関連するリージョン、プロジェクト、オンデマンドクラスターを識別します。 |
| セッション ID | 請求期間を識別します。 |
| 開始時刻と終了時刻 | UTC での請求期間の開始と終了です。秒精度で記録されます。 |
| CU | 請求期間に使用された Query CU 容量です。 |
| 請求対象の分数 | 請求期間に対して請求された分数です。 |
| CU-分 | CU と請求対象の分数から計算された、請求期間の Query CU 使用量です。 |
| 計算 | 使用量の計算方法の説明です。 |

各請求期間は 1 分単位で切り上げられます。エクスポートされた開始時刻と終了時刻は秒精度であるため、それらのタイムスタンプから計算した期間は、元の請求対象の分数を再現できない場合があります。請求対象の使用量を確認する際は、エクスポートの **Billable Minutes** と **CU-minutes** の値を使用してください。

請求セッション ID は請求期間を識別します。これは、クラスター監視ビューで使用される実行 ID とは異なります。1 対 1 のマッピングを前提としないでください。実行は、コンピュートのアクティベーションに関連するリクエストをグループ化しますが、CSV は請求対象の使用量を報告します。実行の詳細については、[オンデマンドクラスターの監視](./monitor-on-demand-cluster) を参照してください。

## Indexing CU 使用量を理解する\{#understand-indexing-cu-usage}

Indexing CU の CSV には、請求書明細項目内のコレクションごとに 1 行が含まれます。

| フィールド | 説明 |
| --- | --- |
| 請求書 ID と請求書明細項目 ID | 請求書と関連する明細項目を識別します。 |
| 請求期間の開始と終了 | UTC での請求期間の開始と終了です。開始は含み、終了は含みません。 |
| リージョン ID、プロジェクト ID、インスタンス ID | 使用量に関連するリージョン、プロジェクト、コンピュートインスタンスを識別します。 |
| データベース ID とデータベース名 | コレクションに関連するデータベースを識別します。 |
| コレクション ID とコレクション名 | この行で請求対象の使用量が集計されるコレクションを識別します。 |
| CU-分 | コレクションについて集計された、請求対象のインデックス作成使用量です。 |
| 計算 | 使用量の計算方法の説明です。 |

各行は請求対象のコレクション使用量を要約したものであり、個々のインデックス作成ジョブを表すものではありません。請求金額については、請求書が正式な情報源です。

## ダウンロードのトラブルシューティング\{#troubleshoot-downloads}

| 問題 | 対処方法 |
| --- | --- |
| 使用量の詳細が不完全であるか、請求書と一致しません。 | 請求書が更新されてから再試行するか、サポートに連絡してください。部分的なファイルは提供されません。 |
| 使用量の詳細がダウンロード上限を超えています。 | 完全なエクスポートについてサポートに連絡してください。 |
| 進行中のエクスポートリクエストが多すぎます。 | 後で再試行してください。 |
| ネットワーク、権限、またはセッションの問題により、ダウンロードが失敗します。 | 接続とアクセスを確認してから、再試行してください。 |
