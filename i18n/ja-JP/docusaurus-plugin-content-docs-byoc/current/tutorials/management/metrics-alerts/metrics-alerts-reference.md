# メトリクスリファレンス

このページでは、組織のメトリクスと、Serving クラスターおよびそのコレクションのメトリクスについて説明します。

## 組織のメトリクス\{#organization-metrics}

組織のメトリクスは、ライセンスの有効性、ライセンス対象の CPU コア使用量、組織内のすべてのプロジェクトにわたる請求を対象とします。金額は米ドルで表示されます。

| Metric | Description |
| --- | --- |
| ライセンスの有効性（日） | 組織のライセンスが期限切れになるまでの残り日数です。更新のしきい値は 60 日未満です。ライセンスが期限切れになると、クラスターの作成とスケーリングが制限される場合があります。 |
| ライセンス対象コア使用率（%） | 使用中の CPU コア数を、ライセンス対象のコア数に対する割合で示します。70% を超える値は、容量に近づいていることを示します。100% の場合は、ライセンス対象のすべてのコアが使用されています。 |
| 過去 1 日間の使用額（&#36;） | 過去 1 日間に発生した使用料金の合計です。 |
| クレジットの有効性（日） | 無料クレジットが期限切れになるまでの日数です。 |
| 残りのクレジット（&#36;） | 未使用の無料クレジットの残高です。 |
| クレジットカードの有効性（日） | 保存されている支払いカードが期限切れになるまでの日数です。 |
| 前払い残高（&#36;） | 前払い済み資金の残高です。 |

## Serving クラスターのメトリクス\{#serving-cluster-metrics}

これらのメトリクスは、コンソールの **Serving クラスター** に一覧表示されるクラスターに適用されます。クラスターレベルの値はクラスター全体を対象とし、コレクションレベルの値は 1つのコレクションを対象とします。コンソールで使用できるチャートはクラスタータイプによって異なります。

### Pod とコンテナのリソース\{#pod-and-container-resources}

これらの BYOC メトリクスは、Pod とそのコンテナの CPU、メモリ、ネットワーク使用量を測定します。

| Metric | Description |
| --- | --- |
| CPU Usage (core) | Pod が使用する CPU コア数です。 |
| CPU Usage Rate for Limit (%) | Pod の CPU 使用量を、Pod の CPU 上限に対する割合で示します。 |
| Memory Usage (MB) | キャッシュを除いた、Pod 内のコンテナが使用するメモリです。 |
| Memory Usage Rate for Limit (%) | Pod のメモリ使用量を、Pod のメモリ上限に対する割合で示します。 |
| Network Inbound Flow (Mbps) | Pod への受信ネットワークトラフィックをメガビット/秒で示します。 |
| Network Outbound Flow (Mbps) | Pod からの送信ネットワークトラフィックをメガビット/秒で示します。 |

### リソース\{#resources}

これらのメトリクスはクラスター全体を測定します。Query CU とレプリカのメトリクスは BYOC クラスターに適用されます。

| Metric | Description |
| --- | --- |
| Query CU Computation (%) | クエリノードの CPU 使用量を、その CPU 上限に対する割合で示します。高い値が継続する場合は、クエリ実行が使用可能な CPU 上限に近づいていることを示します。 |
| Query CU Capacity (%) | ロード済みデータが使用するメモリの割合と、使用中のクラスターストレージクォータの割合のうち、高い方の値です。高い値が継続する場合は、これらのリソースの少なくとも 1つが上限に近づいていることを示します。 |
| Total Query CU (count) | レプリカあたりの Query CU 数にレプリカ数を掛けた値です。レプリカあたり 2 Query CU、レプリカが 2つある場合は、合計 4 Query CU になります。 |
| Replica (count) | クラスター内のレプリカ数です。 |
| Storage (GB) | データとインデックスに使用される永続ストレージです。*すべての Serving クラスタータイプに適用されます。* |

### パフォーマンス\{#performance}

各項目に制限が明記されていない限り、これらのメトリクスは、クラスターレベルとコレクションレベルの両方で、すべての Serving クラスタータイプに適用されます。

| Metric | Description |
| --- | --- |
| QPS（読み取り） | 操作別に分類された 1 秒あたりの読み取りリクエスト数です。各リクエストは、複数のクエリベクトルを含む場合でも 1 回としてカウントされます。 |
| QPS（書き込み） | insert、bulk insert、upsert、delete の各操作における 1 秒あたりの書き込みリクエスト数です。 |
| 1 秒あたりの検索 NQ | 1 秒あたりに検索リクエストに含まれるクエリベクトル数です。1つの検索リクエストに複数のベクトルを含めることができます。 |
| 書き込みスループット (エンティティ/sec) | 書き込み操作全体で 1 秒あたりに書き込まれるエンティティ数です。1つの書き込みリクエストで複数のエンティティが対象になる場合があります。 |
| 読み取りレイテンシ（ms） | 読み取りリクエストを送信してから応答を受信するまでの平均時間または 99 パーセンタイル（P99）時間です。 |
| 書き込みレイテンシ（ms） | 書き込みリクエストを送信してから応答を受信するまでの平均時間または 99 パーセンタイル（P99）時間です。 |
| 読み取りリクエストの失敗率（%） | 検索およびクエリを含む読み取りリクエストの報告失敗率を、パーセントで示します。 |
| 書き込みリクエストの失敗率（%） | 書き込みリクエストの報告失敗率を、パーセントで示します。 |
| スロークエリ数 (counts/min) | 1 分あたりのスロークエリ数です。デフォルトでは、レイテンシが 5 秒を超えるクエリがスロークエリと見なされます。*BYOC クラスターで利用できます。* |
| クラスターの書き込みパフォーマンス容量（%） | クラスターの書き込みレート上限に対する、現在の書き込みレートの割合です。値が 80% を超える場合は、書き込みレートを下げることを検討してください。*クラスターレベルのみです。BYOC クラスターで利用できます。* |
| flush 操作数 (counts/min) | 1 分あたりの flush 操作数です。flush が頻繁に実行されると、クラスターのパフォーマンスが低下する可能性があります。*クラスターレベルのみです。BYOC クラスターで利用できます。*（[Zilliz Cloud の制限事項](./limits#flush)） |
| キャッシュヒット率（%） | クエリ全体の平均キャッシュヒット率です。各クエリのヒット率は、（スキャンした総データ − スキャンしたコールドデータ）/ スキャンした総データです。*クラスターレベルのみです。階層型ストレージと Milvus 2.6.x を備えた BYOC クラスターが対象です。* |

### データ\{#data}

これらのメトリクスは、コレクションとエンティティをカウントします。各項目に別段の指定がない限り、すべての Serving クラスタータイプにわたってクラスター全体に適用されます。

| Metric | Description |
| --- | --- |
| コレクション数 | クラスター内のコレクション数です。 |
| エンティティ数 | 単一 insert と bulk insert を含め、クラスターまたはコレクションに挿入されたエンティティ数です。*個々のコレクションでも利用できます。* |
| ロード済みエンティティ数（概算） | ロード済みエンティティ数の概算です。*BYOC クラスターが対象です。個々のコレクションでも利用できます。* |
| アンロード済みコレクション数 | 現在アンロードされている、クラスター内のコレクション数です。*BYOC クラスターで利用できます。* |
