# describe

この操作はボリュームの詳細を取得します。

## 使用方法\{#usage}

```bash
zilliz volume describe [OPTIONS]
```

**OPTIONS:**

- **--name** (*string*) -

    **[REQUIRED]**

    ボリューム名。

## 例\{#example}

```bash
zilliz volume describe --name my-volume
```
