# get

この操作は設定値を取得します。

## Synopsis\{#synopsis}

```bash
zilliz configure get <KEY>
```

## Options\{#options}

- **KEY** (*string*) -

    **[REQUIRED]**

    対象の設定項目の名前を示します。

## Example\{#example}

```bash
zilliz configure get output
```
