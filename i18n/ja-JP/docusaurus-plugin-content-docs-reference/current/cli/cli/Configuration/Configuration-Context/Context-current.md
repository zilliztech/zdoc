# current

この操作は現在の context を表示します。

## Synopsis\{#synopsis}

```bash
zilliz context current
[--output <json | table | text>]
```

## Options\{#options}

- **--output, -o** (*string*) -

    出力形式を指定します。選択肢: `json`, `table`, `text`.

## Example\{#example}

```bash
zilliz context current
```
