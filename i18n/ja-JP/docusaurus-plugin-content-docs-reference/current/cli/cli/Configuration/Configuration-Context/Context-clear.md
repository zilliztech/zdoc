# clear

この操作はアクティブな cluster context を削除します。Cluster ID、endpoint、database、plan はすべてクリアされます。organization を切り替える前、または古い context 状態のトラブルシューティング時に使用してください。

## 概要\{#synopsis}

```bash
zilliz context clear
```

## 例\{#example}

```bash
zilliz context clear
```
