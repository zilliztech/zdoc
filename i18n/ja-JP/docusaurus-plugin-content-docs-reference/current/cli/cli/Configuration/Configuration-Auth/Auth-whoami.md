# whoami

この操作は、現在サインインしている ID、解決されたコントロールプレーンエンドポイント、および切り替え可能な組織の一覧を表示します。エイリアス: `zilliz info`。

## 概要\{#synopsis}

```bash
zilliz whoami
```

## 例\{#example}

```bash
zilliz whoami
```
