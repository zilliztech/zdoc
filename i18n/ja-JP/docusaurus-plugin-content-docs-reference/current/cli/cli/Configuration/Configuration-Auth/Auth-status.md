# status

この操作は現在の認証ステータスを表示します。

**注:** `zilliz auth status` は後方互換性のために残されている非推奨のエイリアスです。新しいスクリプトでは `zilliz whoami`（エイリアス `zilliz info`）を使用してください。

## Synopsis\{#synopsis}

```bash
zilliz auth status
```

## Example\{#example}

```bash
zilliz auth status
```
