# Go SDK リファレンス

Milvus および Zilliz Cloud の公式 Go SDK は、ベクトルデータベース操作のためのネイティブ Go クライアントを提供します。

## バージョン

- **[Go SDK v1](./v1)** — レガシーバージョン（リポジトリはアーカイブ済み）。既存のアプリケーションでのみ使用してください。
- **[Go SDK v2](./v2)** — 現行バージョン。メインの Milvus リポジトリでメンテナンスされています。

## リポジトリ

- **v1（アーカイブ済み）:** [milvus-io/milvus-sdk-go](https://github.com/milvus-io/milvus-sdk-go)
- **v2（現行）:** [milvus-io/milvus/client](https://github.com/milvus-io/milvus/tree/master/client)
