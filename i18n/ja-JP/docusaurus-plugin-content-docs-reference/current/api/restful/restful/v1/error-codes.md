# エラーコード (v1)

このページでは、Zilliz Cloud RESTful API (v1) によって返されるエラーコードを一覧表示します。


**80000**

不正なパラメータ: xxx

**80001**

トークンが不正です

**80002**

トークンが無効です

**80003**

`pageSize` のパラメータ値は 5 から 100 の間である必要があります。

**80004**

`currentPage` パラメータの値は 1 から Int の最大値までの間である必要があります。

**80005**

無効な clusterType です。パラメータ値は `Performance-optimized` または `Capacity-optimized` のいずれかである必要があります。

**80006**

無効な cuSize です。パラメータ値は 1 から 256 の間である必要があります。

**80007**

この CU Size では大きなリソース消費が必要です。使用する場合は、まず Billing ページでカードの紐付けを完了してください。

**80008**

32 CUs を超える cluster を作成したい場合は、まず当社までお問い合わせください。

**80009**

無効な clusterName です。英数字およびハイフンのみを含めることができます。

**80010**

重複した ClusterName です。同じ名前の実行中の Cluster がすでに作成されています。管理の複雑化を避けるため、名前を変更して新しく作成してください。"

**80011**

`description` の長さが 256 文字の上限を超えています。

**80012**

無効なパスワード入力です。パスワードルールは次のとおりです:\n1. パスワードの文字数は 8 から 64 の間である必要があります。\n2. パスワードは、大文字、小文字、数字、特殊文字のうち任意の 3 種類で構成されている必要があります。\n3. 特殊文字には次が含まれます: !@#$%^&*()_+-=

**80014**

入力された cuSize 値はまだサポートされていません。

**80020**

無効な clusterId であるか、その Cluster にアクセスする権限がありません。

**80021**

Serverless cluster はこの操作をサポートしていません。

**80022**

Dedicated cluster はこの操作をサポートしていません。

**90001**

collection xxx は存在しません。既存の collection の一覧を表示するには ListCollections を使用できます。

**90002**

返り値のプロパティ xxx は collection xxx に存在しません。

**90003**

無効な式です。式の使用方法については、ドキュメントを参照してください: https://milvus.io/docs/boolean.md#Boolean-Expression-Rules

**90004**

`limit` のパラメータ値は 1 から 100 の間である必要があります。

**90005**

`offset` のパラメータ値は 0 未満であってはなりません。

**90006**

属性 xxx は vector 型ではないため、近似検索には使用できません。

**90007**

フィールド xxx の vector 次元が一致しません。入力 vector の次元は xxx ですが、期待される vector 次元は xxx です。

**90008**

現在、Milvus は主キー以外のプロパティに対するフィルタリングおよび削除をサポートしていません。式では主キーフィルタリングを使用してください。主キー以外のプロパティに対するフィルタリングおよび削除機能は開発中です。今しばらくお待ちください。

**90009**

挿入された列数が、セットで定義された列数と一致しません。 \{0} 列が挿入されましたが、期待される列数は \{1} 列です。

**90010**

フィールド xxx の型が一致しません。xxx が期待されていますが、代わりに xxx が入力されました。

**90011**

無効な CollectionName です。理由: xxx

**90013**

パラメータ shardsNum の値の範囲は 1 から 32 である必要があります。

**90014**

パラメータ description の長さは 4096 を超えることはできません。

**90015**

フィールドがありません。テーブル定義には、少なくとも 1 つの主キーフィールドと 1 つの vector フィールドを含めてください。

**90016**

主キーフィールドがありません。

**90017**

各 collection には主キーフィールドを 1 つだけ設定できます。

**90018**

主キーフィールドの型は int64 または varchar である必要があります。

**90019**

AutoID は主キーフィールドにのみ追加できます。

**90020**

AutoID は型が int64 の主キーフィールドにのみ追加できます。

**90023**

Varchar 型の長さは 1 から **65535** の間である必要があります。

**90024**

vector 型では次元を指定する必要があります。

**90025**

vector 列の次元は 32 から **32768** の間である必要があります。

**90026**

**90027**
