# BulkFileType

以下の定数を提供する列挙型です。

## 定数\{#constants}

- **PARQUET**

    ファイルタイプを [Parquet](https://parquet.apache.org/) (*.parquet*) に設定します。

- **JSON**

    ファイルタイプを JSON (*.json*) に設定します。

- **CSV**

    ファイルタイプを CSV (*.csv*) に設定します。
