# BulkFileType

BulkFileType インスタンスは、Milvus BulkWriter がサポートする一括データファイルタイプの 1 つを、その数値コードとファイル名の接尾辞とともに保持します。

## 定数\{#constants}

- **PARQUET**

    ファイルタイプを Parquet (*.parquet*) に設定します。

- **JSON**

    ファイルタイプを JSON (*.json*) に設定します。

- **CSV**

    ファイルタイプを CSV (*.csv*) に設定します。
