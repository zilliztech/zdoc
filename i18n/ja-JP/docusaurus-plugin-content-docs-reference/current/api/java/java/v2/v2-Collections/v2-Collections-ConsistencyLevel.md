# ConsistencyLevel

以下の定数を提供する列挙型です。

## Constants\{#constants}

- **STRONG**

    一貫性レベルを **Strong** に設定します。コード値は 0 です。

- **SESSION**

    一貫性レベルを **Session** に設定します。コード値は 1 です。

- **BOUNDED**

    一貫性レベルを **Bounded** に設定します。コード値は 2 です。

- **EVENTUALLY**

    一貫性レベルを **Eventually** に設定します。コード値は 3 です。
